## 2. 지금 main에서 직접 테스트하는 법

### 2.1 서버 띄우기
```bash
scripts/run-server.sh --port 8080 --ui ui
```
첫 실행은 Maven 컴파일 뒤 기본 결과(30초)를 만든다. `data/results/default.json`이 있으면 바로 뜬다. 확인: http://localhost:8080/api/v1/info 에서 `"defaultResult":"READY"`.

### 2.2 위저드로 실제 편성 (데스크톱, 창 너비 1440 이상)
1. http://localhost:8080/studio/ 를 연다. 상단에 "엔진 대기 · 서버 엔진"이 보이면 서버 엔진이 잡힌 것(서버 없이 열면 브라우저 Mock 엔진).
2. ② 검토·실행 → 실행 시간(10·20·30초)·시작 방식을 고르고 「편성 시작」. 지금 일정에 필수 규칙 위반이 있으면 자동으로 "처음부터 새로 짜기"로 바뀐다는 안내가 보여야 한다.
3. 진행 막대·"더 나은 일정을 찾는 중 · 필수 규칙 위반 N건"이 갱신되고, 끝나면 ③ 결과·수정으로 이동, 위반 0건이어야 한다.
4. ② 로 돌아가 「탐색 과정 보기」 → 모달에서 카드가 움직이며 재생되는지, 재생/일시정지/속도/스텝이 되는지.
5. 같은 조건으로 다시 「편성 시작」 → 즉시 끝나야 한다(캐시).
6. 중지 버튼: 실행 중 「중지」 → "사용자 중지"로 끝나고 ③ 이동.

### 2.3 손잡이가 엔진까지 통하는지 (curl)
```bash
# 실제 2025 1차 일정을 기본 허용오차(300km)로 채점
curl -s -X POST localhost:8080/api/v1/score -H 'Content-Type: application/json' \
  -d "{\"problem\": $(cat data/baseball/input_2025.json), \"mode\": \"INITIAL\"}"
```
기대: `[0/0]hard/[0/-400/-573307/-13/-72955]soft`. `problem.settings`에 `"distanceToleranceKm": 100`을 넣으면 거리 편차 감점이 커지고, `"obligationTeams": ["LG","키움","한화","NC","롯데"]`를 넣으면 어린이날 홈 구단이 바뀐다(5개가 아니면 400).

### 2.4 비교·결과·공유 미리보기
- http://localhost:8080/api/v1/compare : 실제 72,955km vs 엔진 63,312km, `diff.totalKmPct` 13.2, 주말 홈 둘 다 11~12.
- http://localhost:8080/api/v1/results/default : plan·score·trace·knobs·title·metrics.
- http://localhost:8080/og/default.png : 1200×630 이미지(한글 폰트 확인).
- 편성 한 번 뒤 `data/results/<id>.json`이 생기고 `/og/<id>.png`도 열린다. 서버를 재시작해도 같은 조건은 즉시 돌아온다.

### 2.4.1 소개 → 편성 → 결과 → 스튜디오 (휴대폰 375에서도)
1. http://localhost:8080/#try 에서 이동거리 단계와 어린이날 홈 5구단을 바꾸고 「편성 시작」. 두산·LG는 잠실을 같이 써서 **둘 중 정확히 하나**만 고를 수 있다(초기해 생성기 제약 `requireOneSharedStadiumHome`).
2. 진행 막대와 "지금까지 가장 좋은 일정: 6x,xxx km · n/10초"가 갱신된다(사전식 점수라 km가 잠깐 늘 수도 있다). 다른 작업이 돌면 "대기 n번째", 같은 IP에서 이미 돌고 있으면 429 안내.
3. 끝나면 `/r/<id>`로 이동. 제목·조건 표가 고른 조건과 같아야 한다. 요청마다 시드가 달라 같은 조건이라도 결과가 조금씩 다르다.
4. 결과 쪽 「편성 스튜디오에서 이어서 다듬기」 → `/studio/?tol=&hol=&cd=&seed=#step=2`. 위저드가 settings·시드·어린이날 이벤트 구장을 싣고 안내 토스트를 띄운다(`App.applyLinkSettings`). 위저드는 자체 시연 일정에서 시작하므로 같은 숫자가 다시 나오지는 않는다.

### 2.6 아직 못 보는 것
- 모바일 화면: 재생기만 ≤700px 레이아웃이 있고, 소개 페이지는 세션 작업 중.
- 실제 도메인·HTTPS·Cloudflare: VM 생성 뒤.

## 3. 알려진 제약
- SCRATCH(새로 짜기)에서는 사용자 핀이 개막전·어린이날 핀으로 덮인다.
- 초기해 생성기는 잠실 홈 3연전 수 = 3연전 슬롯 수를 요구한다(사전 점검 "공유 구장 용량"이 미리 막는다).
- 특정 날짜 홈 불가(콘서트) 손잡이는 아직 엔진에 없다(정의서의 손잡이 4개 중 3번).
- 기본 VM(e2-standard-4)은 시드 4개 병렬(best-of-4). 8개를 원하면 e2-standard-8.
