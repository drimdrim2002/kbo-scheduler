# 7. 이럴 때는 · 막히면

**이 장에서 할 수 있는 일:** 업무 상황마다 어느 설정을 어디서 바꾸는지 찾고, 화면의 알림·표시에서 무엇을 하면 되는지 압니다.

**상황으로 찾으면 7.1, 화면에 보이는 글로 찾으면 7.2입니다.** 절차는 해당 절에 있습니다. 여기 없는 증상은 8장의 문의처로 알려 주세요.

---

## 7.1 이럴 때는: 상황 → 설정

| 상황 | 설정 | 어디서 | 절 |
| :--- | :--- | :--- | :--- |
| 그날 꼭 그 구단이 홈이어야 할 때 | **홈 구장만 지정** | 3단계 주요 이벤트 일정 → 시즌 달력에서 그 날 → **고른 날** | 3.2 |
| 그날 꼭 그 대진이어야 할 때 | **대진까지 고정** | 같은 곳. 홈 구단과 상대를 함께 고름 | 3.2 |
| 이동 부담보다 주말 흥행의 공평이 중요할 때 | **주말·공휴일 격차 줄이기 우선** | 운영 방침·실행 → **우선순위** | 4.1 |
| 이동 거리를 횟수보다 먼저 보고 싶을 때 | **직접 정하기**로 이동 거리를 1순위에 | 운영 방침·실행 → **지금 순위** ▲▼ | 4.1 |
| 한 목표의 격차를 더 줄이고 싶을 때 | 그 목표의 **허용 수준**을 좁힘 | 운영 방침·실행 → **목표마다 허용 수준** | 4.2 |
| 결과 대부분은 좋은데 몇 연전만 바꾸고 싶을 때 | 연전 **고정** 또는 **홈 지정** → **나머지 자동 편성** | 일정 자세히 보기 → **연전 기간 고정** 띠 | 5.5 |
| 한 경기만 다른 날로 옮기고 싶을 때 | **옮기기…** → **여기로** → **검사하고 저장** 또는 **나머지 자동 편성** | 일정 자세히 보기 → 달력 | 5.5 |
| KBO가 개막일·올스타전 날짜를 발표했을 때 | 그 줄 **수정** | 2단계 시즌 기간·연전 묶음 | 3.1 |
| KBO가 발표한 개막 대진의 상대가 다를 때 | **개막 2연전 홈** 줄 **수정** → 상대 고르기 | 3단계 주요 이벤트 일정 | 3.1 |
| 임시 공휴일이 생겼을 때 | **공휴일·가중치** 줄 **수정** → **줄 추가** | 3단계 → 달력에서 수정 → **1 공휴일과 가중치** | 3.1 |
| 어느 결과를 확정할지 모르겠을 때 | 둘을 골라 **고른 두 버전**의 「여기서 갈림」을 읽음 | 실행 결과 비교 | 6.2 |
| 결과를 다른 사람에게 넘길 때 | **요구 사항 점검** → **엑셀로 받기**, 또는 ⋯ → **내려받기** | 현재 결과 분석 · 실행 결과 비교 | 6.5 |

**특정 날 구장을 쓸 수 없을 때(대관 등)**와 **시즌 중 취소 경기를 다시 넣을 때**는 지원 예정입니다. 지금은 그 설정이 없습니다. 어떤 상황에서 필요한지 8장의 문의처로 보내 주시면 설계에 씁니다.

---

## 7.2 막히면: 증상 → 대처

화면에 적힌 글을 그대로 찾으세요.

| 증상 | 원인 | 대처 |
| :--- | :--- | :--- |
| **이 방침으로 실행**이 눌리지 않는다 | 사전 점검에 진행 불가 항목이 있습니다. 허용 수준 구역 아래에 「사전 점검에 진행 불가 n건이 있어 실행할 수 없습니다 — (항목 이름). …」이 보입니다 | 단계 띠의 **편성 조건 입력·검증**으로 돌아가 항목 이름의 곳을 고칩니다. 「구장 간 거리」는 1단계 거리표, 「특별 경기 충돌」은 3단계 홈 구장 지정, 「n연전 자리」·「같이 쓰는 구장 자리」는 2단계 연전 묶음 |
| **다음** 단추가 눌리지 않는다 | 이 단계에 **✓ 수락**하지 않은 줄이 있습니다. 3단계는 개막전 홈 구단이 전년도 순위와 달라도 막힙니다 | 남은 줄을 **✓ 수락**합니다. 개막전은 **전년도 순위대로 되돌리기 ›**를 누릅니다 |
| 「시험용 자동 편성 — 결과가 좋지 않습니다」 표시가 보인다 | 편성 서버에 연결되지 않아 브라우저 안의 시험용 자동 편성을 씁니다. 결과가 나쁘고, 요구 사항 점검이 없고, 확정할 수 없습니다 | 편성 서버 주소로 다시 엽니다. 연결이 되지 않으면 8장의 문의처로 알립니다 |
| 실행이 끝났는데 목표가 「넘음」이다 | 허용 수준이 너무 좁거나, 지정·고정이 많아 찾을 여지가 적습니다. 2·3순위의 「넘음」은 1순위를 지키느라 내준 것일 수 있습니다 | 1순위면 **수준 다시 정하기**로 허용을 조금 넓히거나 지정·고정을 줄입니다. 2·3순위면 받아들일지, 순서를 바꿀지 정합니다 |
| 「실행이 끝났지만 반드시 지킬 규칙을 지키지 못해 저장하지 않았습니다.」 | 지정이 서로 부딪히거나 연전 묶음이 규칙과 다릅니다. 저장 이름 자리에 「규칙을 어겨 저장하지 않음」이 보입니다 | **요구 사항 점검**에서 어긴 항목을 보고, 3단계 지정과 2단계 묶음을 확인한 뒤 다시 실행합니다 |
| 「같은 조건으로 전에 실행한 결과를 바로 가져왔습니다.」 | 편성 조건·운영 방침·실행 시간이 전과 모두 같아 새로 짜지 않았습니다. 고장이 아닙니다 | 다른 결과를 원하면 허용 수준이나 실행 시간을 조금이라도 바꿉니다 |
| 「처음부터 다시 짤 수 없어 지금 일정에서 이어서 고칩니다.」 · 「고정한 연전이 많아 새로 짤 수 없습니다 · 고정을 줄여 보세요」 | 고정한 연전이 많습니다. 앞은 이어서 풀어 결과가 나온 것이고, 뒤는 그것도 안 된 것입니다 | 결과가 괜찮으면 그대로 씁니다. 더 바꾸려면 시즌 띠에서 고정을 풀고 다시 **나머지 자동 편성**을 누릅니다 |
| 「고정한 것끼리 위반이 있어 실행하지 않았습니다.」 · 「필수 규칙 위반 n건이 있어 저장하지 않았습니다.」 | 고정한 연전·손으로 놓은 경기·홈 지정끼리 반드시 지킬 규칙이 어긋납니다 | 열린 위반 목록의 **그 자리로 ›**로 가서 고정을 풀거나 경기를 다시 놓습니다 |
| **확정** 단추가 없는 줄이 있다 | 「시험용 자동 편성」 표시가 붙은 버전입니다 | 편성 서버에 연결해 같은 방침으로 다시 실행합니다 |
| 「자동 편성 오류: …」 · 「편성 실패 — …」 | 편성 서버가 실행을 끝내지 못했습니다. 뒤에 붙은 글이 이유입니다 | 한 번 더 실행합니다. 되풀이되면 뒤에 붙은 글과 함께 8장의 문의처로 알립니다 |
