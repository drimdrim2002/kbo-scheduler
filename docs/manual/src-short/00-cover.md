# 매치봇 스튜디오 운영 매뉴얼 · 핵심판

**KBO 시즌 일정 편성 · 운영자용**

| | |
| :--- | :--- |
| 적용 버전 | 매치봇 스튜디오 2027 편성 화면 (2026-11-07 화면 기준) |
| 시행일 | (조판 때 기입) |
| 대상 | KBO 일정 편성 운영자 |
| 범위 | 1차 편성 전체. 시즌 중 다시 짜기는 지원 예정 |
| 만든 곳 | 시프트랩 · admin@everyshift.co.kr |

**이 책은 전체판 운영 매뉴얼에서 처음 한 바퀴와 날마다 쓰는 설정만 추린 핵심판입니다.** 화면 이름과 화면의 글은 위 적용 버전의 화면 그대로입니다. 모든 설정의 기본값과 범위, 반드시 지키는 규칙의 전체 목록, 자주 묻는 질문은 전체판에 있습니다.

### 차례

| 장 | 언제 읽나 | 화면 위 단계 띠 |
| :--- | :--- | :--- |
| 1 매치봇 스튜디오가 하는 일 | 처음. 자동 편성과 운영자가 각자 무엇을 맡는지 | — |
| 2 한 바퀴 따라 하기 | 처음. 설명회에서 그대로 따라 합니다 | 1 → 2 → 3 → 4 |
| 3 편성 조건 | 미리 채운 조건을 고칠 때 | 1 **편성 조건 입력·검증** |
| 4 운영 방침 | 방침을 바꿔 실행할 때 | 2 **운영 방침·실행** |
| 5 결과 읽기와 고치기 | 결과를 읽을 때, 몇 연전만 고칠 때 | 3 **현재 결과 분석** |
| 6 비교와 확정 | 고르고 확정할 때, 내보낼 때 | 4 **실행 결과 비교** |
| 7 이럴 때는 · 막히면 | 상황에서 설정을 찾을 때, 화면의 알림이 낯설 때 | — |
| 8 용어 · 문의 | 말뜻을 찾을 때, 물어볼 때 | — |

### 표기 약속

| 표기 | 뜻 |
| :--- | :--- |
| **굵게** | 화면에 있는 단추·제목·칸 이름 그대로. 예: **이 방침으로 실행** |
| 「…」 | 화면에 나오는 글·표시·알림을 그대로 옮긴 것. 예: 「요구 사항 n개 모두 지킴」 |
| 1. 2. 3. | 절차. 한 줄에 한 행동. 줄 밑의 들여 쓴 글은 그때 화면의 반응 |
| 참고 · 주의 | 참고는 알아 두면 좋은 것. 주의는 되돌리기 어려운 일(확정, 지우기)에만 붙습니다 |

이 매뉴얼의 독자는 **운영자**이고, 매치봇 스튜디오가 편성 조건과 운영 방침에 따라 일정을 만드는 일은 **자동 편성**입니다. 아직 없는 기능은 **지원 예정**이라고 적습니다.
