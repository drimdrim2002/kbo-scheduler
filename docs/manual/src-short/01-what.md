# 1. 매치봇 스튜디오가 하는 일

**이 장에서 할 수 있는 일:** 자동 편성이 맡는 일과 운영자가 맡는 일을 가르고, 무엇을 설정해야 결과에 반영되는지 압니다.

**자동 편성은 안을 냅니다. 운영자는 설정하고, 안을 비교해 고르고, 시즌 일정으로 확정합니다.**

자동 편성은 반드시 지킬 규칙을 모두 지키는 일정을 몇 분 안에 만듭니다. 그러나 규칙을 지키는 일정은 하나가 아니고, 어느 것이 「가장 좋은」 일정인지도 하나로 정해지지 않습니다. **운영 방침 설명하기** 창은 이렇게 적고 있습니다.

「그런 균형점은 하나가 아니라 여럿이고, 그 가운데 어디에 설지는 자동 편성이 정하지 못합니다.」

그래서 어디에 설지는 운영자가 정합니다. 무엇을 먼저 챙길지 정하고, 그 방침대로 나온 결과를 보고, 그 가운데 하나를 고릅니다.

[그림 1: 「운영자」와 「자동 편성」이 각자 하는 일의 흐름 · 설명 그림(화면 아님) · (전체판 fig-2-1)]

---

## 1.1 자동 편성이 하는 일

**반드시 지킬 규칙을 하나도 어기지 않는 일정을 만들고, 그 가운데 운영 방침에 맞는 더 나은 일정을 찾습니다.**

반드시 지킬 규칙은 일정이라면 꼭 갖춰야 하는 조건입니다. 연전 기간마다 모든 구단이 한 번씩 나오고, 한 구장에서 같은 기간에 두 경기를 하지 않고, 홈 또는 원정은 3연속까지이고, 운영자가 홈 구단을 정한 날에는 그 구단이 홈 경기를 하는 것 같은 규칙입니다. 어느 운영 방침을 고르든 이 규칙은 지키고, 어긴 결과는 저장하지 않습니다. 전체 목록은 전체판 11장에 있습니다.

규칙을 지키는 일정은 셀 수 없이 많습니다. 자동 편성은 그 가운데 운영자가 정한 **우선순위**와 **허용 수준**으로 견주어 더 나은 쪽을 찾아가고, 끝나면 결과를 저절로 저장해 **실행 결과 비교**에 쌓습니다.

---

## 1.2 운영자가 정하는 일

**운영자는 세 가지를 정합니다. 조건이 맞는지, 무엇을 먼저 챙길지, 어느 결과를 시즌 일정으로 쓸지입니다.**

- **조건** — 편성 조건은 미리 채워져 있습니다. KBO 발표 전이라 예상으로 넣은 값에는 「추정」 표시가 붙어 있으니, 맞으면 **✓ 수락**, 다르면 **수정**을 누릅니다. 3장.
- **방침** — 어느 격차를 먼저 줄일지(**우선순위**)와 목표마다 어디까지 봐줄지(**허용 수준**)를 정합니다. 4장.
- **확정** — 방침을 바꿔 가며 실행해 쌓인 결과를 **실행 결과 비교**에서 견주어 하나를 **확정**합니다. 해마다 하나이고, **확정 취소**로 되돌립니다. 6장.

자동 편성이 견주는 목표는 넷입니다. 앞의 셋은 **구단 사이의 격차**(가장 많은 구단 − 가장 적은 구단)이고, 마지막 하나는 **리그 전체의 합**입니다.

| 목표 | 무엇을 세나 |
| :--- | :--- |
| **이동 횟수 격차 줄이기** | 다른 구장으로 옮겨 간 횟수. 멀고 가까움은 보지 않음 |
| **이동 거리 격차 줄이기** | 옮겨 간 거리를 더한 km. 횟수가 같아도 먼 곳을 오가면 커짐 |
| **주말·공휴일 홈 격차 줄이기** | 홈 연전 날짜마다 매긴 점수의 합. 기본은 토·일 1점, 공휴일 2점, 어린이날 3점 |
| **전체 이동 거리 줄이기** | 10구단이 옮겨 간 거리를 모두 더한 값. 격차가 아니라 합. 언제나 마지막 순위 |

이동의 격차와 주말·공휴일 홈의 격차는 함께 최소로 만들 수 없습니다. 한쪽을 맞추면 다른 쪽이 벌어지므로, 어느 쪽을 먼저 챙길지를 운영자가 정합니다. 허용 수준을 넘어도 결과는 나옵니다. 자동 편성은 넘은 만큼을 줄이려 노력하고, 끝까지 못 넣으면 「넘음」인 채로 냅니다.

---

## 1.3 운영자가 설정하는 것

**자동 편성은 운영자가 설정한 것만 압니다.** 중계 일정이나 구단 행사 같은 화면 밖의 사정은 설정으로 바꿔 알려 줘야 결과에 들어갑니다.

| 갈래 | 무엇인가 | 화면에서 설정하는 것 | 잘 설정하는 원칙 |
| :--- | :--- | :--- | :--- |
| **사실** | 이미 정해진 것 | 구장 위치와 거리, 개막일, 올스타 휴식기, 1차 편성 종료일, 쉬는 요일, 공휴일·가중치, 홈 경기 수, 맞대결 경기 수 | 정확하게. 「추정」 표시부터 확인 |
| **지정** | 꼭 이렇게 되어야 하는 것 | 개막 2연전 대진, 어린이날 홈, 아무 날의 **홈 구장 지정**·**대진까지 고정**, 결과에서 연전 고정 | 꼭 필요한 것만. 많이 고정할수록 찾을 여지가 줄고, 너무 많으면 처음부터 다시 짜지 못함 |
| **방침** | 무엇을 먼저 챙길지 | 우선순위 순서, 허용 수준(기본 4회 · 600km · 3점), 실행 시간 | 기본값으로 한 번 실행 → 「넘음」 확인 → 조금씩 바꿔 다시 실행 → 비교 |

> **참고** 「지정」은 한 번 넣으면 이후 모든 실행이 지킵니다. 결과가 기대와 다르면 지정이 너무 많지 않은지부터 봅니다.
