# 8. 용어 · 문의

**이 장에서 할 수 있는 일:** 화면과 이 매뉴얼에 나오는 말의 뜻을 찾고, 막혔을 때 어디에 물을지 압니다.

## 8.1 용어

가나다순입니다. 더 많은 말은 전체판 12장에 있습니다.

| 말 | 뜻 |
| :--- | :--- |
| **격차** | 한 목표에서 가장 많은 구단의 값 − 가장 적은 구단의 값 |
| **고정** | 결과 고치기에서 연전 기간의 대진을 그대로 두는 것. 그 뒤의 실행에서 바뀌지 않음 |
| **안 · 넘음** | 격차가 허용 수준 이하이면 「안」, 크면 「넘음」 |
| **여기서 갈림** | 「고른 두 버전」에서 처음으로 승부가 난 줄에 붙는 표시. 그 줄이 두 버전의 순위를 가름 |
| **연전** | 같은 두 구단이 이어서 하는 경기 묶음(2·3·4연전). 자동 편성은 연전 단위로 짬 |
| **요구 사항 점검** | 서버가 완성된 일정을 날짜별 경기로 풀어 반드시 지킬 규칙을 항목마다 다시 센 판정 |
| **우선순위** | 어느 격차를 먼저 줄일지의 순서. 1순위가 허용 안에 들면 2순위를 봄. 전체 이동 거리는 늘 마지막 |
| **운영 방침** | 우선순위와 허용 수준을 합쳐 부르는 말 |
| **1차 편성** | 시즌 시작부터 1차 편성 종료일까지 연전 단위로 짜는 일정. 남은 경기는 재편성(지원 예정)에서 |
| **자동 편성** | 매치봇 스튜디오가 편성 조건과 운영 방침에 따라 일정을 만드는 일 |
| **지정** | 꼭 이렇게 되어야 한다고 정해 두는 것. 개막 2연전 대진, 어린이날 홈, 홈 구장 지정, 결과에서의 연전 고정·홈 지정. 반드시 지킬 규칙이 됨 |
| **추정** | KBO 발표 전이라 예상으로 넣은 값. 「추정 · 확정 아님」 표시가 붙고, 운영자가 수락하거나 수정함 |
| **허용 수준** | 목표마다 「이만큼 격차는 괜찮다」고 정하는 값. 「여기까지만 맞추고 다음 목표로 넘어가라」는 선 |
| **홈 지정** | 편성 조건에서는 특정 날 홈 경기를 할 구단을 정하는 **홈 구장 지정**(홈 구장만 / 대진까지), 결과 고치기에서는 3연전의 홈 구단을 정하는 것 |
| **확정** | 한 버전을 그 해의 시즌 일정으로 정하는 것. 해마다 하나. 「확정 취소」로 되돌림 |

## 8.2 문의

**문의와 의견은 스케쥴랩으로 보냅니다.** 이메일 admin@everyshift.co.kr.

물어보기 전에 화면의 글을 그대로 7.2에서, 상황은 7.1에서 찾아봅니다. 문의할 때는 어느 화면에서, 무엇을 눌렀는지, 화면에 보인 글 그대로, 그때의 결과 이름을 적습니다. 결과를 함께 보내려면 **실행 결과 비교** → ⋯ → **내려받기**로 받은 파일을 붙입니다. 지원 예정 기능은 어떤 상황에서 필요한지 적어 주시면 설계에 씁니다.

이 핵심판에 없는 것은 **전체판 운영 매뉴얼**에 있습니다. 모든 설정의 기본값과 범위, 반드시 지키는 규칙의 전체 목록(11장), 시즌 중 다시 짜기(8장), 자주 묻는 질문(13장)입니다. 따로 **요약 카드** 1~2쪽이 있어, 한 바퀴 순서와 확정 전 확인 목록만 담아 시즌 직전에 복습할 때 씁니다.
