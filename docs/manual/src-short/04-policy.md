# 4. 운영 방침

**이 장에서 할 수 있는 일:** 우선순위와 허용 수준을 정해 실행하고, 실행 중 화면과 끝 알림을 읽습니다.

**운영 방침은 둘로 이루어집니다.** 어느 격차를 먼저 줄일지(**우선순위**)와 목표마다 어디까지 봐줄지(**허용 수준**)입니다. **운영 방침·실행** 화면(단계 띠 둘째 칸)은 위부터 **운영 방침 정하기** 머리글, **우선순위**(카드 둘과 **직접 정하기**, 오른쪽에 **지금 순위**), **목표마다 허용 수준** 세 줄, 맨 아래 줄의 「지금 방침: …」·실행 시간·**이 방침으로 실행**입니다. 머리글 오른쪽 **운영 방침 설명하기**를 누르면 자세한 설명이 열립니다.

---

## 4.1 우선순위

**어느 격차를 먼저 줄일지 고릅니다.** 1순위가 허용 안에 들어오면 그때부터 2순위를 봅니다. 순서는 「무엇을 먼저」이지 「무엇만」이 아니고, 반드시 지킬 규칙은 어느 순서든 지킵니다.

| 카드 | 지키는 것 | 내주는 것 | 순위 |
| :--- | :--- | :--- | :--- |
| **이동 격차 줄이기 우선 (기본)** | 이동 횟수·거리 격차를 좁힘 | 주말·공휴일 홈 격차가 벌어질 수 있음 | 이동 횟수 → 이동 거리 → 주말·공휴일 → 전체 이동 거리 |
| **주말·공휴일 격차 줄이기 우선** | 주말·공휴일 홈 격차를 좁힘 | 이동 횟수·거리 격차가 벌어질 수 있음 | 주말·공휴일 → 이동 횟수 → 이동 거리 → 전체 이동 거리 |

다른 순서를 원하면 **직접 정하기**를 누릅니다. **지금 순위**에 ▲▼가 붙어 1~3순위를 바꿀 수 있고, 4순위 **전체 이동 거리 줄이기**는 「늘 마지막」입니다. 비교 화면의 순위도 이 순서로 매깁니다.

---

## 4.2 허용 수준

**목표마다 「이만큼 격차는 괜찮다」는 선입니다.** 격차가 허용 수준 이하이면 「안」, 크면 「넘음」입니다. 줄마다 「가장 많은 구단이 가장 적은 구단보다 [−] n [+] 회 넘게 많지 않으면 만족」이라고 적혀 있고, **−**·**+**로 이동 횟수 1회, 이동 거리 50km, 주말·공휴일 1점씩 움직입니다. 기본값은 4회 · 600km · 3점입니다.

[그림 9: 「목표마다 허용 수준」 세 줄 — −·+ 단추와 숫자, 주말·공휴일 줄 밑 안내 · 운영 방침·실행 · (전체판 fig-5-3)]

| 이렇게 두면 | 그 격차는 | 다른 쪽은 |
| :--- | :--- | :--- |
| **좁히면** | 줄이느라 힘을 씁니다. 너무 좁으면 끝까지 못 들어와 「넘음」으로 끝날 수 있습니다 | 다음 순위 격차를 내줍니다 |
| **넓히면** | 쉽게 만족되어, 허용 수준 근처까지 벌어질 수 있습니다 | 다음 순위에 힘을 씁니다 |
| **0** | 「이 목표를 반드시 맞추려 하고 다른 목표를 내줍니다」 | 크게 내줍니다 |
| **기본값의 세 배 이상** | 「이 목표는 사실상 보지 않습니다」 | — |

처음에는 기본값으로 실행합니다. 1순위가 「넘음」이면 허용을 조금 넓히거나 지정을 줄이고, 2·3순위가 「넘음」이면 받아들일지 순서를 바꿀지 정합니다. 한 번에 하나씩 바꾸고 다시 실행합니다.

> **참고** 2027 달력은 주말·공휴일 점수가 10구단에 똑같이 나뉘지 않아 격차가 1점 밑으로 내려가지 않습니다. 줄 밑에 「이 달력은 점수가 10구단에 똑같이 나뉘지 않아, 격차는 가장 좁혀도 1점입니다.」라고 적혀 있습니다. 0으로 두어도 1점까지 맞춥니다.

## 4.3 실행 시간과 실행

**실행 시간은 최대 1~5분, 기본 2분입니다.** 더 나아지지 않으면 그 전에 먼저 끝나므로, 길게 둔다고 늘 그만큼 걸리지는 않습니다. 보통은 기본값 그대로 두고, 아래 줄의 「최대 [−] n [+] 분」에서 바꿉니다.

1. 아래 줄의 「지금 방침: … · 이동 횟수 n회 · 이동 거리 n km · 주말·공휴일 n점」을 읽습니다.
   - 편성 조건을 고친 뒤면 「· 지금 결과에서 이어서」, 홈 지정을 바꾼 뒤면 「· 홈 지정이 바뀌어 처음부터 다시」가 붙습니다. 방침만 바꿨으면 표시 없이 처음부터 짭니다.
2. **이 방침으로 실행**을 누릅니다.
   - 눌리지 않으면 허용 수준 구역 아래에 「사전 점검에 진행 불가 n건이 있어 실행할 수 없습니다 — (항목 이름). 편성 조건 입력·검증으로 돌아가 고치세요.」가 적혀 있습니다(7.2).

---

## 4.4 실행 중 화면과 끝 알림

**머리글에 「찾는 중…」이 보이고, 더 나은 결과가 나올 때마다 아래 숫자가 바뀝니다.** 자동 편성은 먼저 반드시 지킬 규칙을 맞추고, 다음에 1·2·3순위를 허용 안으로 넣고, 모두 들어오면 4순위 전체 이동 거리를 줄입니다. **목표별 격차**의 4순위 칸에 「줄이는 중 · −n km」가 보이면 앞 순위가 모두 들어온 것입니다.

다른 화면에 가도 실행은 계속됩니다. 도중에 끝내려면 머리글 오른쪽 **멈추고 이 결과 쓰기**를 누릅니다. 끝나면 알림이 뜨고 **현재 결과 분석**으로 넘어가며, 결과는 「#번호_방침_허용 수준」 이름으로 저절로 저장됩니다.

| 알림 | 뜻 |
| :--- | :--- |
| 「실행이 끝났습니다(정한 만큼 찾아봄). 「…」(으)로 저장했습니다.」 | 정해 둔 만큼 찾아보고 끝남. 보통 1분 35초 안팎 |
| 「실행이 끝났습니다(고른 최대 시간까지 실행). …」 · 「…(더 나아지지 않아 먼저 끝남). …」 · 「…(직접 멈춤). …」 | 최대 시간까지 찾았음 · 나아지지 않아 먼저 끝남 · **멈추고 이 결과 쓰기**를 누름 |
| 「같은 조건으로 전에 실행한 결과를 바로 가져왔습니다. …」 | 편성 조건·방침·실행 시간이 전과 같아 새로 짜지 않음 |
| 「실행이 끝났지만 반드시 지킬 규칙을 지키지 못해 저장하지 않았습니다.」 | 결과는 보이지만 저장되지 않음. 편성 조건을 확인(7.2) |
