# 원고 표기 약속 (조판·캡처 세션용)

본문이 아니다. 원고(`00-cover.md` … `14-help.md`, `card.md`)를 HTML·PDF로 옮길 때 읽는 메모다. 구성과 규칙의 근거는 `docs/MANUAL_PLAN.md`.

| 원고 표기 | 뜻 | 조판 |
| :--- | :--- | :--- |
| `# 2. …` | 장 제목 | 책갈피·목차 1단계 |
| `## 2.1 …` | 절 제목 | 책갈피·목차 2단계 |
| `### …` | 소제목 | 목차에 넣지 않음 |
| 장 첫머리 `**이 장에서 할 수 있는 일:** …` | 장 안내 한 줄 | 장 제목 밑 안내 줄 모양 |
| `**굵게**` 안의 화면 이름 | 화면에 있는 단추·제목·칸 이름 그대로 | 굵게 |
| `「…」` | 화면에 나오는 글·표시를 그대로 옮긴 것(알림, 표시, 설명 창 문장) | 그대로 |
| `> **참고** …` | 참고 상자 | 참고 상자 |
| `> **주의** …` | 주의 상자 — 확정·지우기처럼 되돌리기 어려운 일에만 | 주의 상자 |
| `[그림 n-m: 무엇을 보여 주나 · 어느 화면]` | 그림 자리. n = 장 번호, m = 장 안 순서 | 캡처를 넣고 「그림 n-m」 캡션. 대괄호 안 설명은 캡션 초안 |
| 번호 목록의 들여 쓴 줄 | 그 단계의 화면 반응 | 단계 번호 밑 이어지는 줄 |

- `>`(인용)는 참고·주의 상자에만 쓴다.
- 3장(따라 하기)은 누르는 단추와 읽는 자리만 적고, 결과 숫자(격차 몇 회·몇 km·몇 점, 전체 이동 거리)는 적지 않는다. 실행마다 달라지기 때문이다(사용자 결정 2026-11-07). 캡처에 숫자가 찍히는 것은 괜찮다.
- 확정·확정 취소의 물음 창은 브라우저의 기본 창이다. 원고의 **확인**은 그 창의 단추 이름이며, 브라우저에 따라 「OK」로 보일 수 있다.
- 캡처 조건: 편성 서버에 연결한 상태(「시험용 자동 편성」 표시 없음), 2027 편성 조건, 1440 너비, 필요한 부분만 잘라 번호 표시.
- 처음 화면을 찍을 때는 「결과 확인」 카드(2025 KBO 실제 일정과 비교 줄)를 잘라 낸다.

## 핵심판(`src-short/`)에서 다른 점

- 그림 번호는 장 번호 없이 책 전체에서 하나로 이어집니다: `[그림 n: 캡션 · 어느 화면 · (전체판 fig-a-b)]`. 괄호 안 `fig-a-b`가 `docs/manual/img/`의 파일 이름이며, 조판 세션이 그 파일을 좁게 잘라 넣습니다. 캡션은 「그림 n」.
- 장은 0(표지·차례)부터 8(용어·문의)까지 아홉 편입니다. 절 번호는 `n.m`.
- 전체판을 가리킬 때는 「전체판 n장」이라고 적습니다.
