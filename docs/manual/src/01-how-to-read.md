# 1. 이 매뉴얼 읽는 법

**이 장에서 할 수 있는 일:** 누가 어느 장을 읽으면 되는지, 글의 약속이 무엇인지 압니다.

**처음이면 2장과 3장을 읽고 한 바퀴 돌아 봅니다. 일하다 막히면 9장·10장에서 찾습니다.**

### 누가 읽나

KBO 시즌 일정을 짜는 운영자입니다. 야구 일정 업무는 잘 알지만 매치봇 스튜디오는 처음이라고 보고 썼습니다. 개발 지식은 필요 없습니다.

### 장 구성

| 장 | 언제 읽나 | 화면 위 단계 띠 |
| :--- | :--- | :--- |
| 2 매치봇 스튜디오가 하는 일 | 처음. 자동 편성과 운영자가 각자 무엇을 맡는지 | — |
| 3 처음 한 번 따라 하기 | 처음. 설명회에서 그대로 따라 함 | 1 → 2 → 3 → 4 |
| 4 편성 조건 입력·검증 | 조건을 고칠 때. 설정마다 상자 | 1 **편성 조건 입력·검증** |
| 5 운영 방침 정하고 실행하기 | 방침을 바꿀 때. 설정마다 상자 | 2 **운영 방침·실행** |
| 6 현재 결과 분석 | 결과를 읽을 때, 몇 연전만 고칠 때 | 3 **현재 결과 분석** |
| 7 실행 결과 비교와 확정 | 고르고 확정할 때, 내보낼 때 | 4 **실행 결과 비교** |

| 10 문제 해결 | 화면의 알림·표시가 낯설 때 | — |

매치봇 스튜디오 화면 위에는 단계 띠가 있고, 일은 네 단계를 차례로 지납니다. 4~7장이 그 네 단계와 하나씩 짝을 이룹니다.

### 표기 약속

| 표기 | 뜻 |
| :--- | :--- |
| **굵게** | 화면에 있는 단추·제목·칸 이름 그대로. 예: **이 방침으로 실행** |
| 「…」 | 화면에 나오는 글·표시·알림을 그대로 옮긴 것. 예: 「요구 사항 n개 모두 지킴」 |
| 누르다 | 단추·칸·칩을 마우스로 한 번 누르는 것 |
| 고르다 | 목록·카드·단추 가운데 하나를 누르는 것 |
| 적다 | 칸에 글자나 숫자를 입력하는 것 |
| 1. 2. 3. | 절차. 한 줄에 한 행동. 줄 밑의 들여 쓴 글은 그때 화면의 반응 |
| [그림 n-m] | 화면 그림. n은 장, m은 장 안의 순서 |

### 알림 상자

> **참고** 알아 두면 좋은 것입니다. 건너뛰어도 절차는 됩니다.

> **주의** 되돌리기 어려운 일(확정, 지우기)에 붙입니다. 누르기 전에 읽습니다.

### 부르는 말

- 이 매뉴얼의 독자는 **운영자**입니다.
- 매치봇 스튜디오가 편성 조건과 운영 방침에 따라 일정을 만드는 일은 **자동 편성**입니다.
- 아직 없는 기능은 **지원 예정**이라고 적습니다. 시즌 중 다시 짜기, 특정 날 구장 사용 불가가 그렇습니다.
