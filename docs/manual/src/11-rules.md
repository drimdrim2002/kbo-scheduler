# 11. 규칙과 기준 목록

**이 장에서 할 수 있는 일:** 자동 편성이 반드시 지키는 규칙, 좋은 일정을 가리는 기준 넷, 모든 설정의 기본값과 범위를 한 곳에서 찾습니다.

**규칙은 반드시 지키고, 기준은 운영 방침에 따라 견줍니다.** 규칙을 어긴 결과는 저장되지 않습니다. 기준은 허용 수준을 넘어도 결과는 나오고 「넘음」으로 표시됩니다.

---

## 11.1 반드시 지키는 규칙

**요구 사항 점검**이 세는 항목입니다. 서버가 완성된 일정을 날짜별 경기로 풀어 항목마다 다시 셉니다. 편성 조건을 그대로 두면 15개이고(「요구 사항 15개 모두 지킴」), 3단계에서 홈 구장을 지정한 날을 더하면 그 날마다 한 항목씩 늘어납니다. 항목마다의 「정한 값」(편성 조건에서 정한 것)과 「출처」(기본값인지 운영자가 정한 것인지)는 **엑셀로 받기**로 받은 파일의 항목별 시트에 적힙니다(7.5).

아래 표의 묶음은 찾아보기 쉽게 나눈 것이고, 화면에는 항목 이름만 나옵니다.

| 묶음 | 항목 | 무엇을 보나 |
| :--- | :--- | :--- |
| 특별 경기 | **개막전** | 개막일 연전의 홈 구단(또는 대진)이 정한 대로인지 |
| | **어린이날** | 어린이날이 든 연전의 홈 구단이 정한 5곳인지 |
| | **(지정한 날 이름)** | 직접 더한 구장 지정: 그 날 연전의 홈 구단(또는 대진)이 정한 대로인지. 3단계에서 홈 구장을 지정한 날마다 하나씩 생김 |
| 경기 수 | **맞대결 경기 수** | 구단 두 곳이 맞붙는 경기 수가 모두 같은지 |
| | **구단별 홈 경기 수** | 구단마다 1차 편성 홈 경기 수가 정한 값인지 |
| 날짜 | **휴식 요일** | 휴식 요일(보통 월요일)에 경기가 없는지. 예외로 정한 날은 뺌 |
| | **휴식기** | 올스타 휴식기처럼 경기 없는 기간에 경기가 없는지 |
| | **시즌 기간** | 모든 경기가 개막일부터 1차 편성 종료일 사이에 있는지 |
| 연전 길이 | **연전 길이** | 첫 연전만 짧을 수 있고(2연전), 나머지는 정한 길이 이상인지 |
| | **시리즈와 기간의 길이** | 시리즈의 연전 수가 배정된 연전 기간의 연전 수와 같은지 |
| 후반기 첫 4연전 | **4연전 대진** | 후반기 첫 4연전이 개막 2연전과 같은 두 구단의 맞대결인지, 홈은 정한 대로인지 |
| 하루 단위 | **날마다 모든 구단 출전** | 경기가 있는 날마다 모든 구단이 꼭 한 번 출전하는지 |
| | **구장마다 한 경기** | 같은 날 한 구장에서 경기가 둘 이상 잡히지 않았는지(같이 쓰는 구장은 두 구단을 합쳐서) |
| 흐름 | **홈·원정 연속** | 구단마다 홈 또는 원정 연전이 4번 넘게 이어지지 않는지(최대 3연속) |
| | **같은 상대 연속** | 바로 앞 연전과 같은 상대를 잇달아 만나지 않는지 |
| 배정 | **날짜 없는 시리즈** | 모든 시리즈가 연전 기간에 배정되었는지 |

자동 편성이 일정을 만들 때 지키는 규칙도 같은 내용입니다. 연전 기간마다 모든 구단이 한 번씩 출전, 한 구장에 한 경기(같이 쓰는 구장은 한 곳으로), 홈 또는 원정 최대 3연속, 같은 대진 연속 금지, 지정한 날의 홈 구단.

> **참고** 요구 사항 점검에는 「참고」 항목이 있을 수 있습니다. 정한 값이 없어 판정하지 않고 보여 주기만 하는 것입니다(예: 홈 경기 수를 정하지 않았을 때의 구단별 홈·원정 수).

## 11.2 좋은 일정의 기준 네 가지

운영 방침의 순서와 허용 수준으로 견주는 목표입니다. 5장.

| 기준 | 무엇을 세나 | 격차 | 허용 수준 기본값 |
| :--- | :--- | :--- | :--- |
| **이동 횟수 격차 줄이기** | 구단마다 연전을 날짜순으로 놓고, 앞 연전과 다른 구장에서 다음 연전을 하면 1회. 같은 구장이면 0회. 홈·원정 가리지 않고 시즌 합 | 가장 많이 옮긴 구단 − 가장 적게 옮긴 구단 | 4회 |
| **이동 거리 격차 줄이기** | 같은 순서로 앞 연전 구장에서 다음 연전 구장까지의 거리를 모두 더함(km) | 가장 긴 구단 − 가장 짧은 구단 | 600km |
| **주말·공휴일 홈 격차 줄이기** | 홈 연전에 든 날마다 점수를 매겨 더함. 토·일 1점, 공휴일 2점, 어린이날 3점, 평일 0점. 공휴일이 주말과 겹치면 큰 쪽 하나만. 원정 0점 | 가장 높은 구단 − 가장 낮은 구단 | 3점 |
| **전체 이동 거리 줄이기** | 10구단이 옮겨 간 거리를 모두 더한 값(km) | 격차 아님. 리그 전체 합 | 없음. 언제나 마지막 순위 |

- 격차는 평균과의 거리가 아니라 양 끝 두 구단의 차이입니다.
- 허용 수준 이하이면 「안」, 크면 「넘음」입니다. 넘으면 자동 편성은 넘은 만큼을 줄이려 노력하고, 조금 넘은 것보다 많이 넘은 것을 훨씬 무겁게 봅니다.
- 2027 달력은 주말·공휴일 점수 합이 10구단에 똑같이 나뉘지 않아 격차가 1점 밑으로 내려가지 않습니다.

## 11.3 모든 설정의 기본값과 범위

### 편성 조건(4장)

| 설정 | 기본값 | 범위·조건 | 어디서 |
| :--- | :--- | :--- | :--- |
| 구단 이름·구장·위치 | 2025 구단 정보에 LG·두산 구장만 고침(서울 올림픽 주경기장) | 위도·경도는 구장 이름 찾기 또는 지도에서 찍기로만 | 1단계 |
| 구장 간 거리 | 기본 구장 목록의 거리. 「추정」 = 직선거리 × 도로계수, 「도로」 = 길찾기 도로거리 | km, 직접 고칠 수 있음 | 1단계 |
| 쉬는 요일 | 월요일 | 요일 단추로 여러 개 | 2단계 |
| 개막일 | 3월 넷째 토요일(2027-03-27) | 토요일만 | 2단계 |
| 올스타 휴식기 | 7월 둘째 금요일부터 6일 | 시작 날짜와 길이(일) | 2단계 |
| 후반기 첫 4연전 | 휴식기 바로 뒤 목~일 | 휴식기를 옮기면 따라 옮김 | 2단계 |
| 1차 편성 종료일 | 자동 — 필요한 경기일이 되는 첫 일요일(2027은 9/5) | 날짜 직접 또는 「자동으로」 | 2단계 |
| 시즌 종료일 | 10월 31일 | 재편성 기간의 끝. 4단계 확인에 보임 | **모든 표 보기** → **시즌 기본 설정** |
| 연전 묶음 | 규칙대로 자동(3연전 중심, 개막 2연전, 후반기 첫 4연전) | 달력 고치기로 2·3·4연전 묶음 직접 | 2단계 |
| 홈 경기 수(격년 홈) | 홈 73경기 5구단 / 71경기 5구단. 2027 = 홀수 해 묶음 | 구단 단추로 바꿈, 쓰지 않기 가능 | 2단계 홈 경기 수 줄 **수정** · 4단계 시리즈 규칙 |
| 개막 2연전 홈 | 전년도 상위 5구단(잠실은 하나만). 상대는 발표 전 예상값(시범 운영용) | 홈 구단 고정, 상대만 고름(다섯 상대 모두) | 3단계 |
| 어린이날 홈 | 홀수 해 묶음 5구단(두산·LG 중 하나). 발표 전 예상값(시범 운영용) | 5곳 모두 | 3단계 |
| 공휴일 | 정부 공휴일 달력 | 줄 추가·지우기, 법정 공휴일 채우기 | 3단계 수정 화면 |
| 공휴일 가중치 | 공휴일 2, 어린이날 3. 주말 1은 고정 | 0~10 정수 | 3단계 수정 화면 |
| 휴식 요일 공휴일의 경기(「월 경기」) | 꺼짐 | 켜면 그 주 목요일 휴식 | 3단계 수정 화면 |
| 홈 구장 지정 | 개막전·어린이날만 | 아무 날, 하루 5곳까지(개막전·어린이날은 5곳 모두), 홈 구장만 / 대진까지 | 3단계 시즌 달력 |
| 맞대결 경기 수 | 16 | 숫자 | 4단계 시리즈 규칙 |
| 그중 1차 편성 | 15 | 숫자. 바꾸면 1차 편성 종료일이 따라감 | 4단계 시리즈 규칙 |
| 1차 편성 홈(많은 쪽) | 9 | 숫자 | 4단계 시리즈 규칙 |
| 연전 최소 길이 | 3 | 개막 2연전·후반기 첫 4연전 말고는 이 길이 이상 | 4단계 시리즈 규칙 |
| 후반기 첫 4연전 홈 | 개막전 홈 구단 그대로 | 「홈 바꿈」이면 상대 구장 | 4단계 시리즈 규칙 |

### 저장·확정(7장)

| 항목 | 값 |
| :--- | :--- |
| 저장 이름 | #번호_방침_허용 수준(예: #0003_이동격차_4회_600km_3점). 결과 고치기는 「_직접고침」·「_고정후새로짜기」가 더 붙음 |
| 저절로 남는 수 | 이름을 바꾸지 않은 결과는 최근 8개 |
| 저장하지 않는 것 | 반드시 지킬 규칙을 어긴 결과 |
| 비교 | 두 개까지 |
| 확정 | 해마다 하나. 시험용 자동 편성 결과는 불가. 확정한 버전은 지울 수 없음 |
| 「차이 작음」 | 1위와 2위가 전체 이동 거리 3,000km 미만 차이일 때 |
