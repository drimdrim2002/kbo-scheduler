# 14. 도움 받는 곳·의견 보내기

**이 장에서 할 수 있는 일:** 막혔을 때 어디에 물을지, 고치고 싶은 점을 어떻게 보낼지 압니다.

**문의와 의견은 시프트랩으로 보냅니다.**

| | |
| :--- | :--- |
| 문의처 | 시프트랩 |
| 이메일 | admin@everyshift.co.kr |

### 물어보기 전에

1. 화면의 알림·표시 글을 그대로 10장 「문제 해결」에서 찾아봅니다.
2. 상황으로 찾으려면 9장 「이럴 때는」, 말뜻은 12장 「용어 풀이」입니다.
3. 그래도 안 되면 아래를 적어 보냅니다.

### 문의할 때 적을 것

- 어느 화면에서(단계 띠의 이름, 예: 운영 방침·실행)
- 무엇을 눌렀는지
- 화면에 보인 글 그대로(알림, 「…」 표시)
- 그때의 결과 이름(예: #0003_이동격차_4회_600km_3점). 결과를 함께 보내려면 **실행 결과 비교** → ⋯ → **내려받기**로 받은 파일을 붙입니다.

### 의견·개선 요청

- 화면의 글이 어렵거나, 단추 자리가 불편하거나, 없는 기능이 필요하면 같은 주소로 보냅니다.
- 지원 예정으로 적힌 것(시즌 중 다시 짜기, 특정 날 구장 사용 불가)은 요청이 많은 순으로 만듭니다. 어떤 상황에서 필요한지 적어 주시면 그대로 설계에 씁니다.
- 이 매뉴얼에서 화면과 다른 곳을 찾으면 쪽수와 함께 알려 주세요. 다음 판에 고칩니다.

### 요약 카드

매뉴얼과 따로 1~2쪽 **요약 카드**가 있습니다. 한 바퀴 순서와 확정 전 확인 목록만 담아, 시즌 직전에 복습할 때 씁니다. 책상에 두고 쓰도록 만들었습니다.
