# 12. 용어 풀이

**이 장에서 할 수 있는 일:** 화면과 이 매뉴얼에 나오는 말의 뜻을 찾습니다. 가나다순입니다.

| 말 | 뜻 |
| :--- | :--- |
| **격차** | 한 목표에서 가장 많은 구단의 값 − 가장 적은 구단의 값. 평균과의 거리가 아니라 양 끝 두 구단의 차이 |
| **고정** | 결과 고치기에서 연전 기간의 대진을 그대로 두는 것. 고정한 연전은 「나머지 자동 편성」과 그 뒤의 실행에서 바뀌지 않음. 시즌 띠에서 풂 |
| **기본 제공** | 처음부터 들어 있는 버전(「2027 기본안」·「2027 2순위 대진안」). 실행 결과 비교에 늘 함께 줄 서고, 확정할 수 있음 |
| **남김** | 이름을 바꾼 결과에 붙는 표시. 최근 8개 밖으로 밀려도 지우지 않음 |
| **대진까지 고정** | 홈 구장 지정의 한 방식. 그 날 홈 구단과 상대까지 정함. 자동 편성은 그 시리즈를 고정함 |
| **반드시 지킬 규칙** | 일정이라면 꼭 갖춰야 하는 조건. 어느 방침이든 지키고, 어긴 결과는 저장하지 않음. 11.1 |
| **방침과 견주기** | 현재 결과 분석 맨 위 줄. 목표마다 「허용 안」 또는 「n 넘음」 |
| **버전** | 저장된 결과 하나. 실행할 때마다 저절로 저장되고, 실행 결과 비교에 쌓임 |
| **손으로 놓은 경기** | 결과 고치기에서 「옮기기…」로 운영자가 자리를 정한 경기. 「손」 표시가 붙고 그 자리에 고정됨 |
| **수락** | 편성 조건의 추정값이 맞다고 답하는 것. 2·3단계 줄마다 「✓ 수락」 |
| **시험용 자동 편성** | 편성 서버에 연결되지 않았을 때 브라우저 안에서 도는 자동 편성. 결과가 좋지 않고 확정할 수 없음 |
| **안 · 넘음** | 격차가 허용 수준 이하이면 「안」, 크면 「넘음」 |
| **여기서 갈림** | 실행 결과 비교의 「고른 두 버전」에서 처음으로 승부가 난 줄에 붙는 표시. 그 줄이 두 버전의 순위를 가름 |
| **연전** | 같은 두 구단이 이어서 하는 경기 묶음(2·3·4연전). 자동 편성은 연전 단위로 짬 |
| **연전 기간** | 달력에서 연전 하나가 들어가는 날짜 묶음. 2027은 45개 안팎. 연전 기간마다 다섯 경기가 열림 |
| **요구 사항 점검** | 서버가 완성된 일정을 날짜별 경기로 풀어 반드시 지킬 규칙을 항목마다 다시 센 판정. 자동 편성의 점수와 따로 셈 |
| **우선순위** | 어느 격차를 먼저 줄일지의 순서. 1순위가 허용 안에 들면 2순위를 봄. 전체 이동 거리는 늘 마지막 |
| **운영 방침** | 우선순위와 허용 수준을 합쳐 부르는 말. 「이동 격차 줄이기 우선」, 「주말·공휴일 격차 줄이기 우선」, 「직접 정한 순서」 |
| **운영자** | 이 매뉴얼의 독자. 편성 조건을 확인하고, 운영 방침을 정해 실행하고, 결과를 비교해 확정하는 사람 |
| **일정 자세히 보기** | 현재 결과 분석의 세부 화면. 달력 · 홈/원정 흐름 · 상대별 경기 수 탭과, 맨 위의 결과 고치기 띠 |
| **1차 편성** | 시즌 시작부터 1차 편성 종료일까지 연전 단위로 짜는 일정. 맞대결마다 15경기, 구단당 135경기. 남은 경기는 재편성에서 |
| **자동 편성** | 매치봇 스튜디오가 편성 조건과 운영 방침에 따라 일정을 만드는 일. 반드시 지킬 규칙을 모두 지키는 일정 가운데 방침에 맞는 더 나은 것을 찾음 |
| **재편성** | 1차 편성 기간 뒤에 취소 경기와 잔여 경기를 날짜마다 배정하는 일. 지원 예정. 8장 |
| **전체 이동 거리** | 10구단이 옮겨 간 거리를 모두 더한 값. 격차가 아니라 합. 허용 수준이 없고 늘 마지막 순위 |
| **지정** | 꼭 이렇게 되어야 한다고 정해 두는 것. 개막 2연전 대진, 어린이날 홈, 홈 구장 지정, 결과에서의 연전 고정·홈 지정. 반드시 지킬 규칙이 됨 |
| **추정** | KBO 발표 전이라 예상으로 넣은 값. 「추정 · 확정 아님」 표시가 붙고, 운영자가 수락하거나 수정해야 함 |
| **허용 수준** | 목표마다 「이만큼 격차는 괜찮다」고 정하는 값. 이하이면 「안」. 「이 목표는 여기까지만 맞추고 다음 목표로 넘어가라」는 선 |
| **확정** | 한 버전을 그 해의 시즌 일정으로 정하는 것. 해마다 하나. 처음 화면의 「결과 확인」에 나옴. 「확정 취소」로 되돌림 |
| **홈 구장 지정** | 특정 날 홈 경기를 할 구단을 정하는 것. 「홈 구장만 지정」(상대는 자동 편성) 또는 「대진까지 고정」 |
| **홈 지정(결과에서)** | 결과 고치기의 시즌 띠에서 3연전의 홈 구단을 정하는 것. 편성 조건의 홈 구장 지정과 같은 효력 |
| **홈/원정 흐름** | 구단마다 한 줄 띠로 홈·원정 연전의 순서를 보여 주는 보기. 4연속 이상은 빨간 밑줄 |
