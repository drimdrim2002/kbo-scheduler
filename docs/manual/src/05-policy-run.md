# 5. 운영 방침 정하고 실행하기

**이 장에서 할 수 있는 일:** 우선순위와 허용 수준을 정해 실행하고, 실행 중 화면을 읽고, 어떤 설정이 결과를 어떻게 움직이는지 압니다.

**운영 방침은 두 가지로 이루어집니다.** 어느 격차를 먼저 줄일지(**우선순위**)와 목표마다 어디까지 봐줄지(**허용 수준**)입니다. 여기에 실행 시간을 정해 **이 방침으로 실행**을 누릅니다.

**운영 방침·실행** 화면은 단계 띠의 둘째 칸입니다. 편성 조건 네 단계를 마쳐야 들어갈 수 있습니다.

| 자리 | 무엇 |
| :--- | :--- |
| 맨 위 | **운영 방침 정하기** 머리글, 지금 방침의 자리를 보여 주는 띠, 목표 네 칸 |
| 가운데 | **우선순위** — 방침 카드 둘과 **직접 정하기**, 오른쪽에 **지금 순위** |
| 그 아래 | **목표마다 허용 수준** — 세 줄 |
| 맨 아래 줄 | 「지금 방침: …」, 실행 시간 「최대 n 분」, **이 방침으로 실행** |

[그림 5-1: 운영 방침·실행 전체 — 머리글과 띠, 우선순위, 그 아래 허용 수준, 아래 줄 실행 단추 · 운영 방침·실행]

머리글의 말을 먼저 읽습니다. 「이동 격차와 주말·공휴일 홈 격차, 둘 다 최소로 만들 수는 없습니다. 어느 쪽에 무게를 둘지는 운영자의 몫이고, 운영의 묘는 여기서 드러납니다.」 자세한 설명은 머리글 오른쪽 **운영 방침 설명하기**를 누르면 오른쪽에 열립니다. 읽으면서 방침을 만질 수 있습니다.

---

## 5.1 목표 네 개

**앞의 셋은 구단 사이 격차이고 허용 수준이 있습니다. 전체 이동 거리는 리그 전체의 합이고 허용 수준이 없으며 언제나 마지막 순위입니다.**

| 목표 | 무엇을 세나 | 격차 |
| :--- | :--- | :--- |
| **이동 횟수 격차 줄이기** | 다른 구장으로 옮겨 간 횟수. 멀고 가까움은 보지 않음 | 가장 많이 옮긴 구단 − 가장 적게 옮긴 구단 |
| **이동 거리 격차 줄이기** | 옮겨 간 거리를 더한 km. 횟수가 같아도 먼 곳을 오가면 커짐 | 가장 긴 구단 − 가장 짧은 구단 |
| **주말·공휴일 홈 격차 줄이기** | 홈 연전 날짜마다 매긴 점수의 합. 기본은 토·일 1점, 공휴일 2점, 어린이날 3점 | 가장 높은 구단 − 가장 낮은 구단 |
| **전체 이동 거리 줄이기** | 10구단이 옮겨 간 거리를 모두 더한 값. 격차가 아니라 합 | — |

세는 법은 **운영 방침 설명하기** 창에 있습니다. 이동 횟수는 「앞 연전과 다른 구장에서 다음 연전을 하면 1회로 셉니다. 같은 구장에서 이어지면 0회입니다」. 주말·공휴일 점수는 「공휴일이 주말과 겹치면 큰 쪽 하나만」이고 「원정은 0점입니다」.

---

## 5.2 우선순위

**어느 격차를 먼저 줄일지 고릅니다.** 1순위가 조금이라도 나은 결과를 고르고, 2순위는 1순위가 같을 때만 봅니다. 반드시 지킬 규칙은 어느 순서든 지킵니다.

1. 카드 둘 가운데 하나를 누릅니다.
   - 누른 카드에 「선택」이 붙고, 머리글 띠의 파란 점이 그쪽으로 옮겨 갑니다(「카드를 고르면 점이 옮겨 갑니다」). 오른쪽 **지금 순위**에 1~4순위가 보입니다.

| 카드 | 지키는 것 | 내주는 것 | 순위 |
| :--- | :--- | :--- | :--- |
| **이동 격차 줄이기 우선 (기본)** | 이동 횟수·거리 격차를 좁힘 | 주말·공휴일 홈 격차가 벌어질 수 있음 | 이동 횟수 → 이동 거리 → 주말·공휴일 → 전체 이동 거리 |
| **주말·공휴일 격차 줄이기 우선** | 주말·공휴일 홈 격차를 좁힘 | 이동 횟수·거리 격차가 벌어질 수 있음 | 주말·공휴일 → 이동 횟수 → 이동 거리 → 전체 이동 거리 |

2. 다른 순서를 원하면 **직접 정하기**를 누릅니다.
   - **지금 순위**에 ▲▼ 화살표가 붙습니다(「순서는 오른쪽 「지금 순위」에서 화살표로 바꿉니다.」). 1~3순위만 바꿀 수 있고, 4순위 **전체 이동 거리 줄이기**에는 「늘 마지막」이 붙어 움직이지 않습니다.
   - 아래 줄의 방침 이름이 「직접 정한 순서」로 바뀝니다.
   - 예: 이동 거리를 1순위로 두려면 **이동 거리 격차 줄이기**의 ▲를 누릅니다.

[그림 5-2: 「직접 정하기」를 고른 상태의 「지금 순위」 — ▲▼ 화살표와 「늘 마지막」 · 운영 방침·실행]

| 설정 상자 | 우선순위 |
| :--- | :--- |
| 무엇을 정하나 | 세 격차의 순서. 전체 이동 거리는 늘 마지막 |
| 기본값 | 이동 횟수 → 이동 거리 → 주말·공휴일 → 전체 이동 거리 |
| 바꾸면 | 1순위 격차가 가장 먼저 허용 안으로 들어가고, 뒤 순위는 내줍니다. 비교 화면의 순위도 이 순서로 매깁니다 |
| 언제 바꾸나 | 이동 부담보다 주말 흥행의 공평이 중요할 때 → **주말·공휴일 격차 줄이기 우선**. 거리를 횟수보다 먼저 보려 할 때 → **직접 정하기** |
| 결과에서 확인 | **방침과 견주기**의 순서, **목표별 격차** 칸의 「n순위」 |

> **참고** 순서를 바꾸는 것은 「무엇을 먼저」이지 「무엇만」이 아닙니다. 1순위가 허용 안에 들어오면 그때부터 2순위를 봅니다. 그래서 허용 수준이 함께 중요합니다.

---

## 5.3 허용 수준

**목표마다 「이만큼 격차는 괜찮다」는 선을 정합니다.** 격차가 허용 수준 이하이면 「안」, 크면 「넘음」입니다. 좁힐수록 그 격차는 줄고, 다른 쪽 격차는 커질 수 있습니다.

줄마다 「가장 많은 구단이 가장 적은 구단보다 [−] n [+] 회 넘게 많지 않으면 만족」이라고 적혀 있습니다.

1. **−**·**+**로 값을 옮기거나 숫자를 직접 적습니다.
   - 한 번에 이동 횟수 1회, 이동 거리 50km, 주말·공휴일 1점씩 움직입니다.
2. 두 끝에서는 안내가 나옵니다.
   - 0: 「이 목표를 반드시 맞추려 하고 다른 목표를 내줍니다」. 주말·공휴일은 「이 목표를 될 수 있는 한 맞추고 다른 목표를 내줍니다(0은 될 수 없어 1점까지)」.
   - 기본값의 세 배 이상: 「이 목표는 사실상 보지 않습니다」.

[그림 5-3: 「목표마다 허용 수준」 세 줄 — −·+ 단추와 숫자, 주말·공휴일 줄 밑 안내 · 운영 방침·실행]

| 설정 상자 | 허용 수준 |
| :--- | :--- |
| 무엇을 정하나 | 세 격차마다 「여기까지면 같다고 본다」는 값 |
| 기본값 | 이동 횟수 4회 · 이동 거리 600km · 주말·공휴일 3점 |
| 바꾸면 | **좁히면** 그 격차를 줄이느라 다음 순위 격차를 내줍니다. 너무 좁으면 끝까지 못 들어와 「넘음」인 채로 끝날 수 있습니다. **넓히면** 그 목표는 쉽게 만족되어 다음 순위에 힘을 씁니다. 대신 그 격차는 허용 수준 근처까지 벌어질 수 있습니다 |
| 언제 바꾸나 | 기본값으로 실행한 결과의 **방침과 견주기**에서 「넘음」을 본 뒤. 조금씩 |
| 결과에서 확인 | **방침과 견주기**의 「허용 안」·「n 넘음」, **목표별 격차**의 초록 띠, **실행 결과 비교**의 「같다고 봄」 |

허용 수준과 우선순위는 이렇게 맞물립니다. **운영 방침 설명하기** 창의 말입니다(괄호 안에는 지금 방침의 목표 이름이 들어갑니다). 「1순위(…)가 허용 수준 안에 들어오면 만족으로 보고, 그때부터 2순위(…)로 결과를 가립니다. 1순위를 넘은 두 결과는 2순위가 아무리 좋아도 1순위를 덜 넘은 쪽을 고릅니다.」

> **참고** 2027 달력은 주말·공휴일 점수 합이 10구단에 똑같이 나뉘지 않아 격차가 1점 밑으로 내려가지 않습니다. 줄 밑에 「이 달력은 점수가 10구단에 똑같이 나뉘지 않아, 격차는 가장 좁혀도 1점입니다.」라고 적혀 있습니다. 허용을 0으로 두어도 됩니다. 1점까지 맞춥니다.

### 움직이는 요령

- 처음에는 기본값으로 실행합니다.
- 결과에서 「넘음」인 목표를 봅니다. 1순위가 「넘음」이면 허용을 조금 넓히거나 지정을 줄입니다. 2·3순위가 「넘음」이면 받아들일지, 순서를 바꿀지 정합니다.
- 한 번에 하나씩 바꾸고 다시 실행합니다. 결과가 **실행 결과 비교**에 쌓이므로 되돌아갈 수 있습니다.

---

## 5.4 실행 시간

**최대 1~5분 가운데 고릅니다.** 더 나아지지 않으면 최대 시간 전에 먼저 끝납니다.

1. 아래 줄의 「최대 [−] n [+] 분」에서 **−**·**+**를 누르거나 숫자를 적습니다.

| 설정 상자 | 실행 시간 |
| :--- | :--- |
| 무엇을 정하나 | 자동 편성이 더 나은 일정을 찾는 최대 시간 |
| 기본값 | 2분 |
| 바꾸면 | 길게 두면 더 찾아볼 시간이 생깁니다. 다만 절반 동안 나아지지 않으면 그때 끝나므로, 길게 둔다고 늘 그만큼 걸리지는 않습니다 |
| 언제 바꾸나 | 보통은 기본값 그대로. 더 오래 찾아보게 하려면 늘립니다 |
| 결과에서 확인 | 끝났을 때 알림 「정한 만큼 찾아봄」·「더 나아지지 않아 먼저 끝남」·「고른 최대 시간까지 실행」, **현재 결과 분석** 둘째 줄의 「실행 n분」 |

> **참고** 편성 서버의 한도가 고른 시간보다 짧으면 「서버 한도가 n초라 그 시간까지만 실행합니다.」라고 알려 줍니다.

## 5.5 실행하기

**아래 줄의 「이 방침으로 실행」을 누릅니다.** 처음부터 짤지 전 결과에서 이어서 풀지는 자동으로 정해집니다.

1. 아래 줄의 「지금 방침: … · 이동 횟수 n회 · 이동 거리 n km · 주말·공휴일 n점」을 읽고 맞는지 봅니다.
   - 편성 조건을 고친 뒤면 「· 지금 결과에서 이어서」, 홈 지정을 바꾼 뒤면 「· 홈 지정이 바뀌어 처음부터 다시」가 뒤에 붙습니다. 운영 방침만 바꿨거나 결과가 없으면 아무 표시 없이 처음부터 짭니다.
2. **이 방침으로 실행**을 누릅니다.
   - 화면이 실행 중 화면으로 바뀝니다.

단추가 눌리지 않으면 사전 점검에 진행 불가 항목이 있는 것입니다. 허용 수준 구역 아래에 「사전 점검에 진행 불가 n건이 있어 실행할 수 없습니다 — (항목 이름). 편성 조건 입력·검증으로 돌아가 고치세요.」라고 적힙니다. 10장 「문제 해결」을 보세요.

> **참고** 「시험용 자동 편성 — 결과가 좋지 않습니다」 표시가 보이면 편성 서버에 연결되지 않은 것입니다. 실행은 되지만 결과를 확정할 수 없습니다.

## 5.6 실행 중 화면

**머리글에 「찾는 중…」이 보이고, 그 아래는 현재 결과 분석과 같은 구성입니다.** 더 나은 결과가 나올 때마다 숫자가 바뀝니다.

[그림 5-4: 실행 중 화면 — 「찾는 중…」 머리글, 「멈추고 이 결과 쓰기」, 아래 목표별 격차와 구단별 한눈에 · 운영 방침·실행]

| 자리 | 무엇 |
| :--- | :--- |
| 머리글 | 「찾는 중…」, 「지금까지 가장 좋은 결과」, 「n 지남 · 반드시 지킬 규칙을 모두 지키는 중(또는 규칙을 맞춰 가는 중) · 더 나은 결과가 나오는 대로 받아 옵니다 · 더 나아지지 않으면 최대 시간 전에 끝납니다」 |
| 머리글 오른쪽 | **멈추고 이 결과 쓰기** |
| 왼쪽 | **목표별 격차** — 칸마다 지금 값과 「안」·「넘음」. 4순위 칸에 「줄이는 중 · −n km」 또는 「1~3순위 다음 차례」 |
| 오른쪽 | **구단별 한눈에** |
| 아래 줄 | 「실행 중 — 지금 방침: …」, **멈추고 이 결과 쓰기** |

자동 편성은 단계를 밟습니다. 먼저 반드시 지킬 규칙을 맞추고, 다음에 1·2·3순위를 허용 안으로 넣고, 모두 들어오면 4순위 전체 이동 거리를 줄입니다. 4순위 칸의 「줄이는 중」이 보이면 앞 순위가 모두 들어왔다는 뜻입니다.

1. 기다립니다. 단계 띠나 **데이터** 메뉴로 다른 화면에 가도 실행은 계속됩니다. 단계 띠의 둘째 칸에는 「실행 중」이 보입니다.
   - 처음 화면에는 「계획을 실행하는 중입니다. 끝나면 결과 화면으로 넘어갑니다.」와 **실행 화면으로 ›**가 보입니다.
   - 브라우저의 뒤로를 누르면 「계획을 실행하는 중입니다」 창이 「실행을 멈추고 이동하거나, 계속 실행하며 이 화면에 머뭅니다.」라고 묻습니다. **계속 실행** 또는 **실행 멈추고 이동**을 누릅니다.
2. 도중에 끝내려면 **멈추고 이 결과 쓰기**를 누릅니다.
   - 그때까지 찾은 가장 좋은 일정으로 끝납니다.
3. 끝나면 알림이 뜨고 **현재 결과 분석**으로 넘어갑니다.

| 알림 | 뜻 |
| :--- | :--- |
| 「실행이 끝났습니다(정한 만큼 찾아봄). 「…」(으)로 저장했습니다.」 | 정해 둔 만큼 찾아보고 끝남. 보통 1분 35초 안팎 |
| 「실행이 끝났습니다(고른 최대 시간까지 실행). 「…」(으)로 저장했습니다.」 | 최대 시간까지 찾았음 |
| 「실행이 끝났습니다(더 나아지지 않아 먼저 끝남). …」 | 절반 동안 나아지지 않아 먼저 끝남 |
| 「실행이 끝났습니다(직접 멈춤). …」 | **멈추고 이 결과 쓰기**를 누름 |
| 「같은 조건으로 전에 실행한 결과를 바로 가져왔습니다. …」 | 편성 조건·방침·실행 시간이 전과 같아 새로 짜지 않음 |
| 「실행이 끝났지만 반드시 지킬 규칙을 지키지 못해 저장하지 않았습니다.」 | 결과는 보이지만 저장되지 않음. 편성 조건을 확인 |

## 5.7 저장되는 이름

실행이 끝나면 결과가 저절로 저장됩니다. 이름은 「#번호_방침_허용 수준」입니다.

- 번호는 실행마다 1씩 늘어납니다(네 자리).
- 방침은 「이동격차」, 「주말공휴일」, 「직접정하기」 가운데 하나입니다.
- 허용 수준은 바꾼 것만이 아니라 셋 다 적힙니다. 예: 「#0003_주말공휴일_4회_600km_1점」.

이름은 **현재 결과 분석** 둘째 줄의 「저장한 이름」 칸이나 **실행 결과 비교**의 **이름 바꾸기**로 바꿀 수 있습니다. 이름을 바꾼 결과는 지우지 않고 남깁니다. 7장.

## 5.8 결과 고치기 뒤의 실행

**일정 자세히 보기**에서 연전을 고정하거나 경기를 손으로 놓은 뒤(6.5)에는, 아래 줄에 「고정한 연전 n개를 지킵니다」(손으로 놓은 경기가 있으면 「고정한 연전 n개 · 손으로 놓은 경기 m개를 지킵니다」)가 보입니다. 이 화면에서 **이 방침으로 실행**을 눌러도 그것은 지킵니다.

- 홈 지정이 바뀌면 처음부터 다시 짭니다(고정한 것은 그대로).
- 고정한 연전이 너무 많아 처음부터 짤 수 없으면 지금 일정에서 이어서 풉니다. 「처음부터 다시 짤 수 없어 지금 일정에서 이어서 고칩니다.」라고 알려 줍니다.
- 고정을 풀려면 **일정 자세히 보기**의 시즌 띠에서 풉니다.
