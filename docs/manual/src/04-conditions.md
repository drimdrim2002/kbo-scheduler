# 4. 편성 조건 입력·검증

**이 장에서 할 수 있는 일:** 네 단계로 나뉜 편성 조건을 하나씩 확인하고, 다른 값을 고치고, 설정마다 무엇이 바뀌는지 압니다.

**편성 조건은 미리 채워져 있고, 운영자는 맞는지 답합니다.** 네 단계는 **구단 정보** → **시즌 기간·연전 묶음** → **주요 이벤트 일정** → **확인**입니다. 앞 단계를 마쳐야 다음 단계로 갈 수 있고, 네 단계를 모두 마쳐야 실행할 수 있습니다.

| 단계 | 확인하는 것 | 「추정」 |
| :--- | :--- | :--- |
| 1 **구단 정보** | 구단 이름·구장·위치, 구장 간 거리 | — |
| 2 **시즌 기간·연전 묶음** | 쉬는 요일, 개막일, 올스타 휴식기, 1차 편성 종료일, 홈 경기 수 | 3개 |
| 3 **주요 이벤트 일정** | 개막 2연전 홈, 어린이날 홈, 공휴일·가중치, 홈 구장 지정 | 2개 |
| 4 **확인** | 1~3단계 요약과 시리즈 규칙 | — |

이 장의 설정마다 같은 모양의 **설정 상자**를 둡니다. 무엇을 정하나 · 기본값 · 바꾸면 얻는 것과 내주는 것 · 언제 바꾸나 · 결과에서 확인하는 곳입니다.

### 공통 조작

- 각 단계 아래 줄의 **다음: n …**으로 다음 단계로, **이전: n …**으로 앞 단계로 갑니다. 이 단계의 조건을 다 확인하지 않으면 **다음**이 눌리지 않습니다.
- 2·3단계의 줄마다 **✓ 수락** 또는 **수정**이 있습니다. **수정**은 그 줄 안에 입력칸을 펼치거나(2단계), 달력에서 고치는 화면으로 갑니다(3단계).
- 고친 것은 바로 저장됩니다. Ctrl+Z로 실행 취소합니다.
- 처음 값과 달라진 줄에는 「직접 고침」이 붙고, 「처음 추정값은 …였습니다」라고 적힙니다.
- 단계마다 처음 들어가면 「따라 하기 n / 4」 말풍선이 나옵니다. **알겠어요**로 닫고, **따라 하기 다시 보기**로 다시 봅니다.

> **참고** 편성 조건을 고친 뒤 실행하면 전 결과에서 이어서 풉니다. 홈 지정이 바뀌면 처음부터 다시 짭니다. 연전 묶음이 바뀌면 전 결과는 쓸 수 없어 「연전이 바뀌어 다시 실행해야 합니다」라고 알려 줍니다.

## 4.1 1단계 구단 정보

**구단 이름·구장·위치가 작년과 달라진 해만 고칩니다.** 구장 사이 이동 거리는 구장 위치로 계산하므로, 구장이 바뀌면 위치를 다시 찾아야 합니다.

화면은 셋으로 나뉩니다. 위에 「그 밖에 바뀐 정보가 있나요?」 줄, 아래 왼쪽에 **구단·구장** 표, 오른쪽에 **구장 간 거리표**(왼쪽 = 출발 구단, 위 = 도착 구단, 먼 거리는 주황 칸)와 그 밑 **구장 지도**(**펼치기**)입니다.

[그림 4-1: 1단계 전체 — 위 「그 밖에 바뀐 정보가 있나요?」, 왼쪽 구단·구장 표, 오른쪽 구장 간 거리표 · 1단계 구단 정보]

### 그 밖에 바뀐 정보가 있나요?

1. 「이미 고쳐 둔 곳: LG·두산 구장 잠실 → 서울 올림픽 주경기장」을 읽습니다.
   - 잠실야구장을 쓰지 못하는 동안(2027~2031년) 두 구단이 임시로 쓰는 구장입니다. 바로 옆 구장이라 구장 사이 거리는 잠실 값을 그대로 씁니다.
2. 그 밖에 없으면 **✓ 없어요 — 그대로**를 누릅니다. 바로 2단계로 갑니다.
3. 있으면 **있어요 — 고칠게요**를 누릅니다.
   - 단추가 「있어요 — 고치는 중」으로 바뀌고, 「따라 하기 1 / 3」 말풍선이 고치는 법을 차례로 안내합니다(바뀐 구단을 고르세요 → 새 구장 이름을 적고 Enter → 다른 구장까지 거리 확인). **건너뛰기**로 다음 말풍선, 마지막의 **마치기**로 닫습니다.
   - 답을 바꾸려면 **다시 고르기**를 누릅니다.

### 구단 하나 고치기

1. **구단·구장** 표에서 그 구단의 줄을 누릅니다.
   - 표 아래에 「고치기 (구단 이름)」 카드가 열립니다. 왼쪽에 **구단명**, **구장 (Enter = 위치 찾기)**, 읽기 전용 **위도**·**경도**, **지도에서 찍기**가 있고, 오른쪽에 「(구단 이름)에서 다른 구장까지 거리」와 **도로거리 받기**가 있습니다. 카드는 오른쪽 위 ×로 닫습니다.
2. **구장** 칸에 구장 이름을 적고 Enter를 누릅니다.
   - 위치를 찾아 위도·경도를 채웁니다. 하나면 바로 채우고, 여럿이면 목록에서 고르고, 못 찾으면 「「…」을(를) 찾지 못했습니다」라고 알려 줍니다. 이때 구장 이름은 아직 바뀌지 않습니다.
   - 위도·경도는 직접 적지 않습니다. 구장 이름으로 찾거나 **지도에서 찍기**로 지도의 한 점을 눌러 넣습니다.
3. 오른쪽 거리 칸을 확인합니다.
   - 구장 위치가 바뀌면 이 구단의 구장 간 거리를 직선거리로 다시 추정하고, 도로거리를 자동으로 다시 받습니다. 「도로」는 길찾기(자동차)로 받은 도로거리, 「추정」은 직선거리에 도로계수를 곱한 값입니다. **도로거리 받기**로 다시 받을 수 있습니다.
   - 거리 칸은 직접 고칠 수도 있습니다. 숫자를 고치고 Enter를 누르면 직접 적은 값이 됩니다. 이 카드에서 고치면 그 구단에서 **가는** 길만 바뀝니다. 오는 길은 상대 구단을 골라 그 카드에서 고칩니다.
   - 모든 구장의 도로거리를 한꺼번에 다시 받으려면 **구단·구장** 표 아래 **모든 구장 도로거리 계산하기**를 누릅니다.

[그림 4-2: 구단 고치기 카드 — 구장 칸, 「지도에서 찍기」, 거리표와 「도로거리 받기」 · 1단계 구단 정보]

| 설정 상자 | 구단·구장·위치, 구장 간 거리 |
| :--- | :--- |
| 무엇을 정하나 | 10구단의 이름, 홈 구장, 구장 위치(위도·경도), 구장 사이 거리(km) |
| 기본값 | 2025 구단 정보에 LG·두산 구장만 고친 것. 같은 구장을 쓰는 구단은 한 구장으로 셉니다 |
| 바꾸면 | 구장 위치가 바뀌면 그 구단과 관련된 모든 이동 거리가 바뀝니다. 거리가 틀리면 이동 거리 격차와 전체 이동 거리를 잘못 셉니다 |
| 언제 바꾸나 | 구장이 바뀌거나 새로 생긴 해. 거리가 실제와 다르다고 알게 됐을 때 |
| 결과에서 확인 | **현재 결과 분석** → **목표별 격차**의 이동 거리, **구단별 보기**의 총 이동거리 |

## 4.2 2단계 시즌 기간·연전 묶음

**개막일과 1차 편성 종료일이 정해지면 경기일과 연전 묶음은 규칙대로 자동으로 만들어집니다.** 운영자는 날짜가 맞는지 확인합니다.

위 구역 **시즌 기간·연전 묶음**에 줄 다섯이 있고, 오른쪽에 「n / 3 수락」이 보입니다. 아래 구역 **반영 결과**에 경기일 수, 연전 묶음 수(3연전·2연전·4연전), 기간이 보이고 시즌 달력이 있습니다. 편성 조건을 수정하면 바로 다시 셉니다.

[그림 4-3: 2단계 전체 — 위 줄 다섯과 「n / 3 수락」, 아래 「반영 결과」와 달력 · 2단계 시즌 기간·연전 묶음]

| 줄 | 표시 | 고치는 곳 |
| :--- | :--- | :--- |
| 쉬는 요일 | 「2025에서 가져옴」 | **수정** → 요일 단추(일~토) |
| 개막일 | 「추정 · 확정 아님」 | **수정** → 토요일 목록 |
| 올스타 휴식기·후반기 첫 4연전 | 「추정 · 확정 아님」 | **수정** → **시작(금)**·**길이**(일) |
| 1차 편성 종료일 | 「추정 · 확정 아님」 | **수정** → 날짜 |
| 시즌 종료일 | 「기본」 | **수정** → 날짜 |
| 홈 경기 수 | 「규칙대로 자동」 | **수정** → 홈 73 구단 단추 |

「추정 · 확정 아님」 줄은 **✓ 수락**을 누르면 표시가 「✓ 수락」으로 바뀝니다. **수정**은 그 줄 안에 입력칸을 펼치고, 다시 누르거나 **닫기**를 누르면 접힙니다.

### 쉬는 요일

| 설정 상자 | 쉬는 요일 |
| :--- | :--- |
| 무엇을 정하나 | 경기를 하지 않는 요일 |
| 기본값 | 월요일 |
| 바꾸면 | 경기일 수가 바뀌어 1차 편성 종료일과 연전 묶음이 다시 계산됩니다 |
| 언제 바꾸나 | 휴식 요일이 달라진 해. 거의 바꾸지 않습니다 |
| 결과에서 확인 | **일정 자세히 보기**의 달력에서 그 요일이 비어 있는지 |

휴식 요일에 든 공휴일에 경기를 할지는 3단계 공휴일 표의 「월 경기」에서 정합니다.

### 개막일

1. **개막일** 줄의 날짜와 근거를 읽습니다.
   - 근거: 「3월 넷째 토요일에 2연전으로 엽니다(2024 · 2025 · 2026 모두 같음).」
2. 맞으면 **✓ 수락**, 다르면 **수정**을 누릅니다.
   - 「2027 시즌 개막일은 언제인가요?」와 토요일 목록이 펼쳐집니다. 「추천 · 3월 넷째 토요일」이 붙은 날과 앞뒤 토요일 가운데 고르거나, **다른 날…**을 눌러 날짜(예: 4/3)를 적고 Enter를 누릅니다. 토요일만 됩니다. 바꾸지 않으려면 **그대로 두기**를 누릅니다.
   - 고르면 1차 편성 종료일·올스타 휴식기·연전 묶음이 규칙대로 다시 채워집니다.

| 설정 상자 | 개막일 |
| :--- | :--- |
| 무엇을 정하나 | 시즌 첫 경기일. 개막은 토·일 2연전 |
| 기본값 | 3월 넷째 토요일 |
| 바꾸면 | 시즌 전체가 당겨지거나 밀립니다. 연전 묶음이 다시 만들어져 전 결과는 쓸 수 없습니다 |
| 언제 바꾸나 | KBO가 개막일을 발표했을 때 |
| 결과에서 확인 | **일정 자세히 보기**의 달력 첫 주 |

### 올스타 휴식기·후반기 첫 4연전

1. 줄의 기간과 그 밑 「후반기 첫 4연전 …」을 읽습니다.
   - 근거: 「7월 둘째주 토요일을 올스타전으로 잡았고, 그 주 금요일부터 다음주 수요일까지를 올스타전 휴식기로 잡았습니다. 휴식기 바로 뒤 목~일은 4연전으로 묶으며, 휴식기를 수정하면 함께 옮겨집니다.」
2. 맞으면 **✓ 수락**, 다르면 **수정**을 누릅니다.
   - **시작(금)**과 **길이**(일)를 적습니다. 뒤 목~일은 4연전이 됩니다.

| 설정 상자 | 올스타 휴식기 |
| :--- | :--- |
| 무엇을 정하나 | 경기가 없는 기간의 시작 날짜와 길이 |
| 기본값 | 7월 둘째 금요일부터 6일 |
| 바꾸면 | 휴식기와 후반기 첫 4연전이 함께 옮겨지고, 경기일 수가 바뀌어 1차 편성 종료일이 다시 계산됩니다 |
| 언제 바꾸나 | 올스타전 날짜가 발표됐을 때 |
| 결과에서 확인 | **일정 자세히 보기**의 달력 7월, **요구 사항 점검**의 연전 기간 표 |

### 1차 편성 종료일

| 설정 상자 | 1차 편성 종료일 |
| :--- | :--- |
| 무엇을 정하나 | 1차 편성으로 짜는 마지막 날. 그 뒤는 남은 경기와 취소 경기를 넣는 재편성 기간 |
| 기본값 | 자동 — 개막부터 경기일을 세어 필요한 날 수(1차 편성 경기 수로 계산)가 되는 첫 일요일 |
| 바꾸면 | 그 날까지 연전 묶음을 다시 깝니다. 날짜를 직접 적으면 줄에 「직접 고침」이 붙고, 수정 칸에 **자동으로(경기일 n일이 되는 첫 일요일)** 단추가 생깁니다. 누르면 다시 자동 |
| 언제 바꾸나 | 거의 바꾸지 않습니다. 1차 편성 경기 수를 바꾸면 자동으로 따라갑니다 |
| 결과에서 확인 | **반영 결과**의 경기일 수가 필요한 수와 같은지 |

### 시즌 종료일

이 줄에는 **✓ 수락**이 없습니다. 1차 편성에는 쓰지 않는 값이라 확인만 합니다.

| 설정 상자 | 시즌 종료일 |
| :--- | :--- |
| 무엇을 정하나 | 재편성 기간의 끝. 1차 편성 뒤 남은 경기와 취소 경기를 이 날까지 넣습니다 |
| 기본값 | 10월 31일 |
| 바꾸면 | 재편성 기간이 늘거나 줄어듭니다. 1차 편성 결과에는 영향이 없습니다 |
| 언제 바꾸나 | 시즌 마감일이 정해졌을 때. 시즌 중 다시 짜기(8장)가 들어오면 그때 씁니다 |
| 결과에서 확인 | 4단계 확인의 2 시즌 기간·연전 묶음 줄 「시즌 종료 …」 |

### 홈 경기 수

| 설정 상자 | 홈 경기 수(격년 홈 73 / 71) |
| :--- | :--- |
| 무엇을 정하나 | 홈 73경기를 하는 다섯 구단과 71경기를 하는 다섯 구단 |
| 기본값 | 2027은 홀수 해 기준. 근거: 「남는 홈 경기는 해마다 번갈아 가집니다(2027 = 홀수 해).」 |
| 바꾸면 | 구단마다 홈 경기 수가 바뀝니다. 1차 편성 홈 경기 수는 자동으로 맞춥니다 |
| 언제 바꾸나 | 홀수·짝수 해가 바뀌면 자동으로 반대가 됩니다. KBO 방식이 달라졌을 때만 |
| 결과에서 확인 | **요구 사항 점검** → **시즌 합계**의 구단별 홈 경기 수 |

**자세히 ›**를 누르면 「2027 홈 경기 수 근거」 창이 열립니다. **수정**을 누르면 줄 안에 「격년 홈 73 / 71경기」 칸이 펼쳐집니다. 구단 단추를 눌러 홈 73 구단 다섯을 고르고(「홈 73 구단 n / 5곳」), **쓰지 않기**로 격년 홈을 끌 수 있습니다. 같은 칸이 4단계 시리즈 규칙의 **고치기**에도 있습니다.

### 달력 고치기: 연전 묶음

연전 묶음은 규칙대로 만들어지지만, 특정 기간만 다르게 묶고 싶으면 달력에서 직접 고칩니다.

1. **반영 결과** 구역 달력 위의 **달력 고치기**를 누릅니다.
   - 달력 위에 「날짜를 끌면 연전 묶음 · 묶음을 누르면 바꾸기·나누기·지우기」가 보입니다.
2. 날짜를 끌면 2·3·4연전 묶음을 만듭니다.
3. 묶음을 누르면 창이 열립니다. **연전 수**(2연전 · 3연전 · 4연전)를 바꾸거나, **둘로 나누기 (2+2)**(4연전만), **묶음 지우기**를 할 수 있습니다.
   - 창에 바꾸면 경기일이 어떻게 되는지 적힙니다(예: 「2연전으로 바꾸면 …이 경기 없는 날이 되어 경기일 합이 134일이 됩니다.」).
4. **고치기 끝**을 누릅니다.

[그림 4-4: 「달력 고치기」 상태의 달력 — 날짜를 끌어 묶음 만들기, 묶음을 누른 창 · 2단계 시즌 기간·연전 묶음]

> **참고** 연전 묶음을 바꾸면 전 결과는 쓸 수 없습니다. 「연전이 바뀌었습니다」라고 알려 주고, 다음 실행은 처음부터 짭니다. 묶음을 규칙과 다르게 만들면 **운영 방침·실행**의 사전 점검에 「규칙과 다른 묶음이 있습니다」가 보일 수 있습니다.

## 4.3 3단계 주요 이벤트 일정

**정한 날에 홈 경기를 할 구단을 지정합니다.** 나머지 날의 홈·원정은 자동 편성이 정합니다.

위 구역 **주요 일정**에 줄 셋이 있고, 오른쪽에 「n / 2 수락」이 보입니다. 아래 **시즌 달력**에서 공휴일과 홈 구장을 지정한 날이 시즌 어디쯤인지 봅니다. 날을 누르면 달력에서 고치는 화면으로 갑니다.

[그림 4-5: 3단계 전체 — 「주요 일정」 줄 셋과 시즌 달력 · 3단계 주요 이벤트 일정]

### 개막 2연전 홈

1. 줄의 홈 구단 다섯 칩과 「vs 상대」를 봅니다.
   - 홈 구단은 전년도 상위 5구단(잠실을 같이 쓰는 두 구단은 하나만)이고, 상대는 공식 발표 전이라 시범 운영을 위해 예상으로 넣은 값입니다. **자세히 ›**를 누르면 어떻게 정했는지 보여 줍니다.
2. 맞으면 **✓ 수락**, 상대가 다르면 **수정**을 누릅니다.
   - 달력에서 고치는 화면이 열리고, 오른쪽 **고른 날 · 3/27(토)** 칸에 「홈 구단은 고정입니다 — 전년도 순위로 정해집니다. 상대 구단만 고칠 수 있습니다.」가 보입니다. 홈 구단 단추는 눌리지 않습니다.
3. 아래 **대진**(원정 @ 홈)에서 홈 구단마다 상대를 고릅니다.
   - 다섯 상대를 모두 골라야 합니다. 비운 칸이 있으면 「대진의 상대를 모두 고릅니다.」가 보이고, 3단계 줄에는 「상대 자동」이 보이며 **다음: 4 확인**이 눌리지 않습니다.
   - 고친 줄에는 「직접 고침」이 붙고 「직접 고친 값입니다. 처음 추정값은 …였습니다.」가 적힙니다.
4. **검토로 돌아가기**를 누릅니다.

> **참고** 받은 파일을 올리는 등 다른 길로 개막전 홈 구단이 전년도 순위와 달라지면, 줄에 「홈 구단이 전년도 순위와 다릅니다(…). 되돌려야 다음으로 갈 수 있습니다.」와 **전년도 순위대로 되돌리기 ›**가 나옵니다.

| 설정 상자 | 개막 2연전 홈 |
| :--- | :--- |
| 무엇을 정하나 | 개막 2연전의 홈 구단 다섯과 각 상대 |
| 기본값 | 홈 = 전년도 상위 5구단(잠실을 같이 쓰는 두 구단은 하나만). 상대 = 발표 전 예상값(시범 운영용) |
| 바꾸면 | 상대를 바꾸면 그 시리즈가 고정되고, 후반기 첫 4연전(같은 두 구단이 다시 만남)도 따라 바뀝니다 |
| 언제 바꾸나 | KBO 발표(보통 12월 중순)에서 상대가 다를 때 |
| 결과에서 확인 | **일정 자세히 보기**의 달력 첫 주, **요구 사항 점검**의 「개막 연전」 줄 |

### 어린이날 홈

| 설정 상자 | 어린이날 홈 |
| :--- | :--- |
| 무엇을 정하나 | 5월 5일 홈 경기를 하는 다섯 구단 |
| 기본값 | 홀수 해 묶음(해마다 번갈아 맡음). 두산·LG 가운데 하나만. 발표 전 예상값(시범 운영용) |
| 바꾸면 | 그 날 그 구단이 홈이 되도록 자동 편성이 지킵니다. 상대는 자동 편성이 정합니다 |
| 언제 바꾸나 | KBO 발표가 다를 때 |
| 결과에서 확인 | **일정 자세히 보기**의 달력 5월 5일, **요구 사항 점검**의 어린이날 줄 |

**자세히 ›**를 누르면 어떻게 정했는지 보여 줍니다. **수정**은 달력에서 고치는 화면으로 가고, **고른 날 · 5/5(수)** 칸에서 구단 단추를 눌러 다섯 곳을 고릅니다(「5 / 5곳」). 어린이날은 다섯 곳을 모두 골라야 합니다. 두산·LG는 같은 구장이라 하나만 고릅니다.

### 공휴일·가중치

이 줄에는 **✓ 수락**이 없습니다. 1차 편성 기간과 2차 편성 기간의 공휴일이 「1차:」「2차:」 두 줄로 나열되고, 「정부 공휴일 달력 기준입니다」라고 적혀 있습니다. 고치려면 **수정**을 누릅니다.

1. **수정**을 누릅니다.
   - 달력에서 고치는 화면이 열리고, 왼쪽에 **1 공휴일과 가중치** 표가 있습니다. 열은 날짜 · 이름 · 가중치 · 월 경기입니다.
2. 가중치를 바꾸려면 그 줄의 숫자를 고칩니다. 0~10 사이의 정수만 됩니다(벗어나면 「가중치는 0~10 정수입니다(주말 하루 = 1).」).
3. 줄을 더하려면 표 제목 오른쪽 **줄 추가**를 누릅니다.
   - 「임시 공휴일」 줄이 하나 생기고 「… 「임시 공휴일」 줄을 넣었습니다. 날짜·이름·가중치를 고치세요. 연전 묶음은 그대로입니다.」라고 알려 줍니다. 그 줄의 날짜·이름·가중치를 고칩니다.
   - 빼려면 줄 끝의 ×를 누릅니다. 표가 비어 있으면 **2027년 법정 공휴일 채우기**로 한 번에 채웁니다.
   - 표에는 1차 편성 기간의 공휴일만 보입니다. 시즌 앞과 재편성 기간의 공휴일은 표 아래 「1차 편성 기간 밖(시즌 앞·재편성 기간) 공휴일 n일 더 보기」를 누르면 보입니다.
4. 휴식 요일(월)에 든 공휴일에 경기를 하려면 그 줄의 「월 경기」를 켭니다. 휴식 요일이 아닌 공휴일 줄에는 「—」만 있습니다.
   - 켜면 그 주 목요일이 휴식일이 됩니다. 켜고 끌 때 「묶음에 반영할까요?」라고 묻습니다.
5. **검토로 돌아가기**를 누릅니다.

[그림 4-6: 「1 공휴일과 가중치」 표 — 날짜·이름·가중치·월 경기 열, 「줄 추가」 · 달력에서 수정]

| 설정 상자 | 공휴일·가중치 |
| :--- | :--- |
| 무엇을 정하나 | 공휴일 날짜와, 그 날 홈 경기의 가치(점). 주말 하루는 1점으로 고정 |
| 기본값 | 정부 공휴일 달력. 공휴일 2점, 어린이날 3점. 0~10 |
| 바꾸면 | **주말·공휴일 홈 격차 줄이기**가 세는 점수가 바뀝니다. 한 날의 가중치를 크게 하면 그 날 홈을 누가 맡느냐가 격차를 크게 움직입니다 |
| 언제 바꾸나 | 임시 공휴일이 생겼을 때, 특정 공휴일을 더 무겁게 보려 할 때 |
| 결과에서 확인 | **목표별 격차**의 주말·공휴일 홈, **구단별 보기**의 「공휴일 홈」 |

### 홈 구장 지정: 아무 날이나

개막전·어린이날 말고도, 특정 날에 특정 구단이 홈이어야 하면 그 날에 홈 구장을 지정합니다.

1. 3단계 아래 **시즌 달력**에서 그 날을 누릅니다.
   - 달력에서 고치는 화면이 열리고, 오른쪽 **고른 날 · (날짜)** 칸에 그 날의 연전과 **홈 구장 지정** 스위치가 나옵니다.
2. **홈 구장 지정**을 켭니다.
   - 구단 단추 열 개가 나옵니다.
3. 그 날 홈이어야 하는 구단을 누릅니다. 하루 5곳까지입니다.
   - 칸 위에 「n / 5곳」이 보이고, 5곳보다 적으면 「n곳 더 고를 수 있습니다」가 보입니다. 다만 개막전·어린이날이 아닌 날은 고른 구단만 홈으로 지키므로, 그 날 꼭 홈이어야 하는 구단만 골라도 됩니다.
   - 같은 구장을 쓰는 두 구단은 하나만 고릅니다(「서울 올림픽 주경기장은 두산·LG 중 하나만 고릅니다.」).
4. 구단을 고르면 방식 단추가 나옵니다. **대진까지 고정** 또는 **홈 구장만 지정**입니다. 처음에는 **홈 구장만 지정**입니다.
   - **홈 구장만 지정**: 「이 날 홈 경기를 해야 하는 구단을 고릅니다(5곳까지). 상대는 자동 편성이 정합니다.」
   - **대진까지 고정**: 「이 날 홈 구단 5곳과 상대까지 정합니다. 자동 편성은 그 시리즈를 고정합니다.」 아래 **대진**(원정 @ 홈)에서 홈 구단마다 상대를 고릅니다.
5. 왼쪽 **2 홈 구장 지정** 목록에서 지정한 날이 「n곳」 또는 「n곳 · 대진」으로 보이는지 확인합니다. 아직 다 고르지 않았으면 「고르는 중 n / 5」입니다.
   - 지정을 지우려면 그 날을 다시 누르고 **홈 구장 지정**을 끕니다.
6. **검토로 돌아가기**를 누릅니다.

| 설정 상자 | 홈 구장 지정 |
| :--- | :--- |
| 무엇을 정하나 | 특정 날 홈 경기를 할 구단(5곳까지). 대진까지 정할 수도 있음 |
| 기본값 | 개막전·어린이날만 |
| 바꾸면 | 반드시 지킬 규칙이 됩니다. 어느 방침으로 실행해도 지킵니다. 지정이 많을수록 자동 편성이 찾을 여지가 줄어 격차가 커질 수 있습니다 |
| 언제 바꾸나 | 그날 꼭 그 구단이 홈이어야 할 때(행사 등), 그날 꼭 그 대진이어야 할 때 |
| 결과에서 확인 | **일정 자세히 보기**의 달력 그 날, **요구 사항 점검**의 「정한 홈」·「정한 대진」 줄 |

> **참고** 홈 지정을 넣거나 바꾸면 다음 실행은 처음부터 다시 짭니다. 특정 날 구장을 쓸 수 없게 하는 설정(대관 등)은 지원 예정입니다.

## 4.4 4단계 확인

구역 제목은 모두 확인했으면 「검토 완료」, 아니면 「아직 검토할 편성 조건이 남았습니다」이고, 오른쪽에 「n / 4 확인」이 보입니다.

### 시리즈 규칙

시리즈 규칙은 맞대결마다 몇 경기를 하고 그중 몇 경기를 1차 편성에 넣는지입니다. 거의 바꾸지 않습니다. **시리즈(규칙대로 자동)** 줄의 **고치기**를 누르면 입력칸과 「격년 홈 73 / 71경기」 칸이 펼쳐집니다.

| 설정 상자 | 시리즈 규칙 |
| :--- | :--- |
| 무엇을 정하나 | **맞대결**(구단 짝마다 경기 수), **그중 1차 편성**, **1차 편성 홈(많은 쪽)**, **연전 최소 길이**, **후반기 첫 4연전 홈** |
| 기본값 | 맞대결 16, 그중 1차 편성 15, 1차 편성 홈 9, 연전 최소 길이 3, 후반기 첫 4연전 홈은 「개막전 홈 구단 그대로」 |
| 바꾸면 | 1차 편성 경기 수를 바꾸면 필요한 경기일이 바뀌어 1차 편성 종료일이 다시 계산됩니다. 「홈 바꿈」이면 후반기 첫 4연전을 상대 구장에서 합니다 |
| 언제 바꾸나 | 리그 경기 수 방식이 달라진 해 |
| 결과에서 확인 | **일정 자세히 보기** → **상대별 경기 수** 탭의 판정 줄 「모든 맞대결이 n경기(홈 · 원정)로 고릅니다」 |

> **참고** 「시리즈를 만들 수 없습니다」가 보이면 연전 묶음과 시리즈 규칙이 맞지 않는 것입니다. 2단계의 묶음 수나 1차 편성 경기 수를 확인합니다.

## 4.5 검토를 마친 뒤

- 아래 줄 **다음: 운영 방침·실행**을 누르면 단계 띠의 둘째 칸으로 갑니다. 5장.
- 나중에 편성 조건을 고치려면 단계 띠의 **편성 조건 입력·검증**을 누릅니다. 4단계 확인 화면이 열리고, 각 줄의 **고치기**로 그 단계에 갑니다.
- 고친 뒤에는 다시 실행해야 결과에 반영됩니다. 처음 화면에 「고쳤다면 검토 후 다시 실행합니다」라고 적혀 있습니다.
