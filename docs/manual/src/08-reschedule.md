# 8. 시즌 중 다시 짜기

**이 장에서 할 수 있는 일:** 시즌 중 취소 경기와 남은 경기를 다시 넣는 기능이 무엇을 하게 될지 압니다.

**지원 예정입니다.** 지금 화면에서는 할 수 없고, 이 장은 무엇을 하게 될지만 적습니다.

### 무엇을 하나

1차 편성은 연전 단위로 구단당 135경기를 짭니다. 시즌 중 우천·폭염 등으로 열리지 못한 **취소 경기**와, 맞대결마다 하나씩 남겨 둔 **잔여 경기**(구단당 9경기)는 1차 편성 기간이 끝난 뒤 **날짜 하나하나**에 배정합니다. 결과는 「날짜마다 열리는 대진과 구장」입니다.

| 항목 | 내용 |
| :--- | :--- |
| 배정하는 것 | 잔여 경기 + 취소 경기 |
| 배정하는 기간 | 1차 편성 마지막 날의 다음 날부터, 운영자가 정한 날까지 |
| 취소 경기의 홈 | 원래 홈 구단 그대로. 날짜만 다시 정함 |
| 잔여 경기의 홈 | 홈 경기 수 원칙(격년 홈 73 / 71)대로 |
| 언제 짜나 | 1차 편성 기간이 모두 끝난 뒤 한 번에. 새 취소가 생기면 입력을 고쳐 다시 실행 |

### 반드시 지킬 규칙(예정)

- 한 구단은 하루 한 경기. 더블헤더 날만 같은 상대와 두 경기.
- 한 구장은 하루 한 대진. 잠실을 같이 쓰는 두 구단은 같은 날 둘 다 홈일 수 없음.
- 모든 경기를 기간 안에 배정.
- 쉬는 날 없이 이어서 경기하는 날 수의 상한(기본 6일).
- 구단당 더블헤더 상한(기본 2번. 0이면 더블헤더 없음).

### 좋은 일정의 기준(예정)

1차 편성의 운영 방침처럼 순서를 바꿀 수 있습니다. 기본 순서입니다.

1. 구단별 마지막 경기일 맞추기 — 가장 늦게 끝나는 구단과 가장 먼저 끝나는 구단의 차이(기본 3일 이내)
2. 이동 공정성 — 1차 편성과 재편성을 합한 144경기 전체의 이동 횟수·거리 격차
3. 재편성으로 늘어나는 이동 거리 합계
4. 월요일 경기 수 최소
5. 더블헤더 수 최소

### 지금 할 수 있는 것
