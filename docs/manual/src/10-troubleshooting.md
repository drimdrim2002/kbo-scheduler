# 10. 문제 해결

**이 장에서 할 수 있는 일:** 화면에 보이는 증상에서 원인을 찾고, 무엇을 하면 되는지 압니다.

**증상 → 원인 → 대처.** 화면에 적힌 글을 그대로 찾으세요. 여기 없는 증상은 14장의 연락처로 알려 주세요.

---

## 10.1 실행이 안 될 때

### 「이 방침으로 실행」이 눌리지 않는다

| | |
| :--- | :--- |
| 원인 | 사전 점검에 진행 불가 항목이 있습니다. 허용 수준 구역 아래에 「사전 점검에 진행 불가 n건이 있어 실행할 수 없습니다 — (항목 이름). 편성 조건 입력·검증으로 돌아가 고치세요.」가 보입니다 |
| 대처 | 단계 띠의 **편성 조건 입력·검증**으로 돌아가 아래 원인 가운데 해당하는 것을 고칩니다 |

줄 끝의 항목 이름(예: 「— 구장 간 거리 · 특별 경기 충돌」)을 아래 표에서 찾습니다.

| 원인 | 뜻 | 고치는 곳 |
| :--- | :--- | :--- |
| 구장 간 거리 | 거리가 빠진 구단 짝이 있어 이동 거리를 셀 수 없음 | 1단계 구단 정보 → 그 구단 카드의 거리표 |
| 연전 기간 | 연전 묶음이 만들어지지 않음 | 2단계 개막일·1차 편성 종료일 |
| n연전 자리 | 시리즈 수가 그 길이(2·3·4연전)의 연전 기간 × 5보다 많음 | 2단계 **달력 고치기**로 묶음을 맞추거나 4단계 시리즈 규칙 |
| 같이 쓰는 구장 자리 | 잠실을 같이 쓰는 두 구단의 홈 시리즈가 같은 날 겹치게 됨 | 2단계 묶음 또는 4단계 격년 홈 |
| 특별 경기 충돌 | 같은 날 홈 지정이 5곳을 넘거나, 한 구단이 두 대진에 들어가거나, 같은 구장을 두 대진이 씀 | 3단계 → 달력에서 수정 → **2 홈 구장 지정** |
| 시리즈 목록 · 구단 수 짝수 | 시리즈를 만들지 못했거나 구단 수가 짝수가 아님 | 4단계 시리즈 규칙 · 1단계 구단 정보 |

### 「편성 조건 입력·검증을 먼저 마쳐 주세요」 · 「앞 단계의 편성 조건을 모두 확인해 주세요」

| | |
| :--- | :--- |
| 원인 | 네 단계 가운데 아직 **✓ 수락**하지 않은 줄이나 답하지 않은 질문이 있습니다 |
| 대처 | 4단계 확인 화면의 「아직 검토할 편성 조건이 남았습니다」 줄에서 **고치기**로 그 단계에 가서 마칩니다. 1단계는 「바뀐 정보가 있나요?」에 답해야 합니다 |

### 「다음」 단추가 눌리지 않는다

| | |
| :--- | :--- |
| 원인 | 이 단계의 줄 가운데 **✓ 수락**하지 않은 것이 있습니다. 3단계에서는 개막전 홈 구단이 전년도 순위와 달라도 막힙니다 |
| 대처 | 남은 줄을 **✓ 수락**합니다. 개막전은 **전년도 순위대로 되돌리기 ›**를 누릅니다 |

### 「시험용 자동 편성 — 결과가 좋지 않습니다」 표시가 보인다

| | |
| :--- | :--- |
| 원인 | 편성 서버에 연결되지 않아 브라우저 안의 시험용 자동 편성을 씁니다. 결과가 나쁘고, 요구 사항 점검이 없고, 확정할 수 없습니다 |
| 대처 | 편성 서버 주소로 다시 엽니다. 연결이 되지 않으면 14장의 연락처로 알립니다 |

### 「자동 편성 오류: …」 · 「편성 실패 — …」

| | |
| :--- | :--- |
| 원인 | 편성 서버가 실행을 끝내지 못했습니다. 뒤에 붙은 글이 이유입니다 |
| 대처 | 한 번 더 실행합니다. 되풀이되면 뒤에 붙은 글과 함께 14장의 연락처로 알립니다 |

---

## 10.2 결과가 기대와 다를 때

### 실행이 끝났는데 목표가 「넘음」이다

| | |
| :--- | :--- |
| 원인 | 허용 수준이 너무 좁거나, 지정·고정이 많아 자동 편성이 찾을 여지가 적습니다. 2·3순위의 「넘음」은 1순위를 지키느라 내준 것일 수 있습니다 |
| 대처 | **방침과 견주기**에서 어느 목표가 얼마나 넘었는지 봅니다. 1순위면 **수준 다시 정하기**로 허용을 조금 넓히거나, 3단계 홈 지정·시즌 띠의 고정을 줄입니다. 2·3순위면 받아들일지, 순서를 바꿀지 정합니다. 실행 시간을 늘려 보는 것도 됩니다 |

### 「실행이 끝났지만 반드시 지킬 규칙을 지키지 못해 저장하지 않았습니다.」

| | |
| :--- | :--- |
| 원인 | 자동 편성이 시간 안에 반드시 지킬 규칙을 모두 맞추지 못했습니다. 지정이 서로 부딪히거나 연전 묶음이 규칙과 다를 때 그렇습니다 |
| 대처 | 저장 이름 자리에 「규칙을 어겨 저장하지 않음」이 보입니다. **요구 사항 점검**에서 어긴 항목을 보고, 3단계 지정과 2단계 묶음을 확인한 뒤 다시 실행합니다 |

### 「같은 조건으로 전에 실행한 결과를 바로 가져왔습니다.」

| | |
| :--- | :--- |
| 원인 | 편성 조건·운영 방침·실행 시간이 전과 모두 같아 새로 짜지 않았습니다. 고장이 아닙니다 |
| 대처 | 다른 결과를 원하면 허용 수준이나 실행 시간을 조금이라도 바꿉니다 |

### 「연전이 바뀌어 다시 실행해야 합니다」 · 「연전이 바뀌었습니다」

| | |
| :--- | :--- |
| 원인 | 2단계의 개막일·1차 편성 종료일·올스타 휴식기·연전 묶음을 고쳐 전 결과를 이 달력에 쓸 수 없습니다 |
| 대처 | 편성 조건 검토를 마치고 다시 실행합니다. 전 결과가 필요하면 **실행 결과 비교**의 **불러오기**로 가져옵니다. 그러면 편성 조건도 그 버전을 만들 때로 돌아갑니다 |

### 「편성 조건을 고친 뒤로 아직 실행하지 않아 지키지 못한 규칙이 보일 수 있습니다.」

| | |
| :--- | :--- |
| 원인 | 편성 조건을 고쳤지만 결과는 전 것입니다 |
| 대처 | **운영 방침·실행으로 ›**를 눌러 다시 실행합니다. 편성 조건만 고쳤으면 이어서, 홈 지정을 바꿨으면 처음부터 짭니다 |

## 10.3 결과 고치기에서

### 「처음부터 다시 짤 수 없어 지금 일정에서 이어서 고칩니다.」

| | |
| :--- | :--- |
| 원인 | 고정한 연전이 많아 편성 서버가 고정한 채로 처음부터 시작하지 못했습니다. 지금 일정에서 이어서 풀었습니다 |
| 대처 | 결과를 보고 괜찮으면 그대로 씁니다. 더 바꾸고 싶으면 고정을 줄입니다 |

### 「고정한 연전이 많아 새로 짤 수 없습니다 · 고정을 줄여 보세요」

| | |
| :--- | :--- |
| 원인 | 고정한 연전이 너무 많아 이어서 풀기도 되지 않았습니다 |
| 대처 | 시즌 띠에서 고정을 풀고 다시 **나머지 자동 편성**을 누릅니다. 띠 아래 「새로 짤 연전 n개」가 적을수록 어렵습니다 |

### 「고정한 것끼리 위반이 있어 실행하지 않았습니다.」 · 「필수 규칙 위반 n건이 있어 저장하지 않았습니다.」

| | |
| :--- | :--- |
| 원인 | 고정한 연전·손으로 놓은 경기·홈 지정끼리 반드시 지킬 규칙이 어긋납니다 |
| 대처 | 열린 위반 목록의 **그 자리로 ›**로 가서 고정을 풀거나 경기를 다시 놓습니다 |

### 「홈 지정은 3연전에만 합니다.」 · 「한 연전에 홈 지정은 5구단까지입니다. 다른 구단을 먼저 빼세요.」

| | |
| :--- | :--- |
| 원인 | 홈 지정은 3연전에만, 한 연전에 다섯 구단까지입니다 |
| 대처 | 3연전 칸을 고르거나, 다른 구단의 지정을 먼저 뺍니다 |

---

## 10.4 비교·확정에서

### 「확정」 단추가 없는 줄이 있다

| | |
| :--- | :--- |
| 원인 | 「시험용 자동 편성」 표시가 붙은 버전은 편성 서버에 연결되지 않은 채 낸 결과라 확정할 수 없습니다 |
| 대처 | 편성 서버에 연결해 같은 방침으로 다시 실행합니다 |

### 「이 점검표는 지금 보이는 일정의 것이 아닙니다」 · 「다른 일정의 점검표」

| | |
| :--- | :--- |
| 원인 | 실행 뒤 일정을 고쳤거나, 다른 버전의 점검표입니다 |
| 대처 | **요구 사항 점검**에서 **지금 일정 다시 점검**을 누릅니다 |

### 「저장 공간이 모자라 저장하지 못했습니다. 안 쓰는 결과를 지우세요.」

| | |
| :--- | :--- |
| 원인 | 결과를 저장할 자리가 모자랍니다 |
| 대처 | **실행 결과 비교**의 ⋯ → **지우기**로 안 쓰는 버전을 지웁니다. 남길 것은 먼저 **내려받기**로 받아 둡니다. **현재 결과 분석**에 「저장하지 못함」이 보이면 지운 뒤 **다시 저장**을 누릅니다 |

### 「올리지 못했습니다 — …」

| | |
| :--- | :--- |
| 원인 | 올린 파일이 이 시즌의 버전 파일이 아니거나, 구단이 다르거나, 반드시 지킬 규칙을 지키지 못한 일정입니다 |
| 대처 | 뒤에 붙은 이유를 보고, **내려받기**로 받은 파일 그대로를 올립니다 |

### 결과가 다른 컴퓨터에 보이지 않는다

| | |
| :--- | :--- |
| 원인 | 저장한 버전과 확정은 그 컴퓨터의 브라우저에 남습니다 |
| 대처 | **내려받기**로 받은 파일을 다른 컴퓨터에서 **받은 버전 올리기**로 올립니다 |

## 10.5 그 밖에

### 화면의 글자·표가 잘려 보인다

| | |
| :--- | :--- |
| 원인 | 매치봇 스튜디오는 너비 1440 이상의 화면에 맞춰 만들었습니다 |
| 대처 | 브라우저 창을 넓히거나 화면 배율을 줄입니다 |
