# 매치봇 스튜디오 요약 카드

**한 바퀴 순서와 확정 전 확인 목록.** 시즌 직전 복습용. 자세한 절차는 운영 매뉴얼 3~7장.

---

## 한 바퀴

| 단계 띠 | 할 일 | 누르는 것 |
| :--- | :--- | :--- |
| 처음 화면 | 새 계획 시작 | **새 계획 만들기** → **검토 시작**(결과가 있으면 **편성 조건 검토하기**) |
| 1 **편성 조건 입력·검증** | 1단계 구단 정보 | 바뀐 곳 없으면 **✓ 없어요 — 그대로** |
| | 2단계 시즌 기간·연전 묶음 | 「추정」 줄 셋(개막일 · 올스타 휴식기 · 1차 편성 종료일)을 읽고 **✓ 수락** / **수정** |
| | 3단계 주요 이벤트 일정 | 개막 2연전 홈 · 어린이날 홈(발표 전 예상값)을 확인하고 **✓ 수락** / **수정**. 꼭 홈이어야 할 날은 달력에서 그 날을 눌러 **홈 구장 지정** |
| | 4단계 확인 | 「검토 완료 · 4 / 4 확인」 → **다음: 운영 방침·실행** |
| 2 **운영 방침·실행** | 방침 정하기 | **우선순위** 카드 고르기(기본 **이동 격차 줄이기 우선**) · **목표마다 허용 수준**(기본 4회 · 600km · 3점) · 실행 시간(기본 2분) |
| | 실행 | **이 방침으로 실행** → 「찾는 중…」 → 끝나면 저절로 저장 |
| 3 **현재 결과 분석** | 읽는 순서 | ① 요구 사항 점검 「모두 지킴」 → ② **방침과 견주기** 「안」·「넘음」 → ③ **구단별 보기** 몰린 부담 → ④ **일정 자세히 보기** 달력 |
| | 다시 실행 | 「넘음」이 마음에 안 들면 **운영 방침 바꿔 다시 실행**. 몇 연전만 바꾸려면 시즌 띠에서 **고정**/**홈 지정** → **나머지 자동 편성** |
| 4 **실행 결과 비교** | 고르기 | **비교** 칸에 둘 표시 → **고른 두 버전**에서 「같다고 봄」 지나 **「여기서 갈림」** 줄 읽기 |
| | 확정 | 줄 오른쪽 **확정** → 확인. 되돌리기는 **확정 취소** |

**결과는 방침에 따라 달라집니다. 어느 격차를 먼저 줄일지, 어느 결과를 쓸지는 운영자가 정합니다.**

---

## 확정 전 확인 목록

| | 확인할 것 | 어디서 |
| :--- | :--- | :--- |
| ☐ 1 | 요구 사항 점검에서 어긴 항목이 0개인가 | 현재 결과 분석 셋째 줄 · 고른 두 버전 「요구 사항」 줄 |
| ☐ 2 | 1순위 목표가 「안」인가. 「넘음」이 있다면 받아들일 수 있는 정도인가 | 방침과 견주기 · 목표별 격차 |
| ☐ 3 | 구단별 보기에서 한 구단에 몰린 부담이 없는가 | 구단별 한눈에 · 구단별 보기 |
| ☐ 4 | 지정한 것(개막 2연전, 어린이날 홈, 홈 지정, 고정한 연전)이 그대로 들어갔는가 | 일정 자세히 보기 달력 |
| ☐ 5 | 비교한 버전과의 「여기서 갈림」을 보고 이 버전을 고른 이유를 한 줄로 말할 수 있는가 | 고른 두 버전 |

한 줄 예: 「n순위까지는 둘 다 허용 안이라 같다고 보았고, ○○에서 이쪽이 앞서 이 버전을 골랐다.」

## 자주 쓰는 설정

| 이럴 때 | 여기서 |
| :--- | :--- |
| 그날 꼭 그 구단이 홈 | 3단계 달력 → **홈 구장만 지정** |
| 그날 꼭 그 대진 | 3단계 달력 → **대진까지 고정** |
| 주말 흥행의 공평이 먼저 | **주말·공휴일 격차 줄이기 우선** |
| 한 목표의 격차를 더 줄이기 | 그 목표의 허용 수준 **−** |
| 몇 연전만 바꾸기 | 일정 자세히 보기 시즌 띠 **고정** → **나머지 자동 편성** |
| 남길 결과 | ⋯ → **이름 바꾸기**(「남김」) |
| 다른 사람에게 넘기기 | 요구 사항 점검 → **엑셀로 받기** |

## 막히면

| 보이는 글 | 하는 일 |
| :--- | :--- |
| 「시험용 자동 편성 — 결과가 좋지 않습니다」 | 편성 서버 주소로 다시 열기. 확정 불가 |
| 「사전 점검에 진행 불가 n건」 | 편성 조건 입력·검증으로 돌아가 고치기 |
| 실행 중 화면의 지난 시간이 00:00에서 늘지 않음 | 다른 실행을 기다리는 중. 기다리기 |
| 「같은 조건으로 전에 실행한 결과를 바로 가져왔습니다.」 | 고장 아님. 조건·방침·시간 중 하나를 바꾸면 새로 짬 |
| 「고정한 연전이 많아 새로 짤 수 없습니다」 | 시즌 띠에서 고정 줄이기 |
