제 추천 (선택은 직접 보시고): alt-a 편성 스튜디오를 골격으로

  • 주 업무인 SC-2(위반 확인 → 고정·이동 → 재최적화)를 가장 짧게 처리합니다. 위반을 누르면 위치로 이동하고, 인스펙터의 조치 후보를 Hard·Soft Δ와 함께 바로 적용합니다.
  • 모든 단계와 시즌 운영이 같은 3분할 문법이라 한 번 익히면 끝납니다. 시트 표에 행 번호·열 글자가 있어 엑셀 가져오기 오류 위치와 화면이 맞습니다.
  • 약점(밀도, 빈 인스펙터)은 다른 후보의 장점으로 메울 수 있습니다.
    • ① 데이터 준비의 인스펙터를 alt-b식 즉시 결과 패널(연전 수급 막대·시즌 띠)로 바꿉니다.
    • 시트 표는 alt-c의 수식 줄·셀 오류 표식을 가져옵니다.
    • ④ 품질·배포와 구단별 일정표 인쇄는 alt-d의 표·그림 캡션과 인쇄 스타일을 씁니다.
  • 다른 선택: 사용자가 대부분 엑셀로만 일한다면 alt-c, 회의 자료 비중이 크면 alt-d가 낫습니다.
실제 뷰포트 크기의 iframe을 화면에 맞춰 축소해 보여 줍니다. 새 창으로 열면 원래 크기로 쓸 수 있습니다.
