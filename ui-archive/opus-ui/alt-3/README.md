# alt-3 구단 매트릭스 (Team Grid)

> 브랜치 `opus-ui/alt-3` · 요구사항 `KBO_OPUS_UI_REQUIREMENTS.md` §10

## 콘셉트

공정성을 검증하는 의사결정자를 위한 **구단(행) × 슬롯(열) 격자**가 주 화면이다. 한 화면에서 10개 구단의 시즌 전체 홈/원정 흐름, 상대, 이동거리, 연속 길이를 보고, 행 끝에 고정된 공정성 지표로 구단 간 차이를 바로 비교한다.

- **열 머리 = 슬롯 설정**: 날짜·요일·연전·휴일 가중치와 위반 수가 보이고, 누르면 연전·주말·휴일 가중치 수정, 슬롯 일괄 고정, 슬롯 위반·시리즈 목록이 열린다.
- **행 머리 = 구단 설정**: 구단명·구장·공유 구장(⇄)·연속 위반 수가 보이고, 누르면 이름·색·구장 검색·좌표 수정, 구단 강조, 일정표, 경로 보기가 열린다.
- **셀**: H 홈 / A 원정과 상대(또는 이동 km·휴일 가중치·경기 상태). 연속이 3 이상이면 시작 셀에 길이 숫자를 붙이고, 3을 넘는 셀(H0-f)은 빗금과 빨간 밑줄로 표시한다. 셀을 끌어 다른 열(슬롯)로 옮기거나 다른 셀 위에 놓아 맞바꾼다.
- **행 끝 공정성 지표**(오른쪽 고정): 이동거리·이동·휴일·4연속(채점) / 주말홈·최장H·최장A·장거리(참고). 평균 대비 편차와 허용오차 초과 ▲, 머리를 눌러 행 정렬.

다른 기능은 격자 아래 **하단 시트**에서 탭으로 연다. 경계선을 끌거나(또는 화살표 키) 높이를 조절한다.

시각 언어는 밀도 높은 스프레드시트다. 흑연색 상단 바, 각진 칸, 고정폭 숫자, 남보라 신호색, 홈(파랑)·원정(호박) 셀 배경을 쓴다.

## 화면 구성

| 영역 | 내용 |
| :--- | :--- |
| 상단 바 | 점수 배지(H0-e 모드 전환), 실행 취소·다시 실행, 이벤트 시리즈 고정·고정 해제, 스냅샷, 자동 저장 상태 |
| 표시 도구 | 셀 표시(상대 / 이동 km / 휴일 가중치 / 경기 상태), 구단 강조 필터 |
| 격자 | 월 띠, 슬롯 머리(설정), 슬롯 상태 띠(✔/✖), 구단 행, 오른쪽 고정 지표, 리그 평균 행 |
| 하단 시트 탭 | 구단·지도 / 거리 행렬 / 일정 골격·슬롯 / 시리즈 / 이벤트 / 검토·엔진 / 위반·풀 / 캘린더 / 지표·Soft·스냅샷 / 분석 / 경기 기록·재편성 / 구단 일정표 / 설정·데이터 |

- 위반 목록에서 항목을 누르면 격자가 해당 셀·열로 스크롤하고 깜박인다.
- 키보드: 격자 칸 사이 화살표 이동, 머리에서 Enter(설정 열기), 셀에서 Enter → 대상 열 머리/셀에서 Enter(이동·교환), Esc(닫기·선택 해제).

## 실행

```bash
open index.html                         # file://로 바로 실행 (Kakao 외 모든 기능)
python3 -m http.server 8000       # Kakao 사용 시. 개발자 콘솔에 http://localhost:8000 등록
```

작업 상태는 `localStorage`의 `kbo-opus:alt-3:v1`에 자동 저장된다. 코어 테스트는 `node core/test/run-tests.js`.
