# alt-2 시즌 보드 (Calendar Board)

> 브랜치 `opus-ui/alt-2` · 요구사항 `KBO_OPUS_UI_REQUIREMENTS.md` §10

## 콘셉트

날짜 단위로 일하는 편성 담당자를 위한 **대형 월간 달력 중심** 화면이다. 달력은 항상 화면 가운데 있고, 위쪽 **도구 팔레트**로 날짜를 눌렀을 때의 동작을 바꾼다. 공휴일·경기 없는 날·휴식 예외·이벤트를 달력에서 바로 지정하고, 경기 기록과 재편성 배치도 달력에서 한다. 구단·거리·시리즈 같은 입력과 품질·분석은 오른쪽 **슬라이드 패널**로 연다.

직접 조작이 가장 강하다. 시리즈 드래그 이동·교환(Δ 미리보기)에 더해, 날짜 칸의 **⇅ 손잡이를 끌어 슬롯 전체를 다른 슬롯과 통째로 맞바꾼다**(고정 시리즈는 그대로, 놓기 전에 Hard/Soft Δ 표시).

시각 언어는 밝고 둥근 보드다. 흰 지면 위 둥근 날짜 칸, 청록 강조, 알약 모양 버튼, 부드러운 그림자를 쓴다.

## 화면 구성

| 영역 | 내용 |
| :--- | :--- |
| 상단 바 | 점수 배지(H0-e 모드 전환), 빠른 실행(엔진 실행·일시정지·중지·경과), 실행 취소·다시 실행·스냅샷, 자동 저장 상태 |
| 패널 메뉴 | 구단·구장 / 거리 행렬 / 일정 골격·슬롯 / 시리즈 / 이벤트 / 검토·엔진 / 품질·스냅샷 / 분석 / 재편성·현황 / 구단 일정표 / 설정·데이터 |
| 도구 팔레트 (숫자 키 1~7) | ✋ 편성 수정 · 🎌 공휴일 · ⛔ 경기 없는 날 · ⚾ 휴식 예외 · 🎉 이벤트 · 📝 경기 기록 · 🔁 재편성 배치 |
| 달력 | 월 탭(3~10월), 구단 필터(홈 🏠/원정 ✈), 1차 편성·재편성 구간 색 구분, 슬롯 시작 표시·연전·휴일 가중치, 위반 슬롯 테두리·⚠, 이벤트·휴식 예외 표시, ⇅ 슬롯 손잡이 |
| 오른쪽 레일 | 선택한 날(슬롯·위반·시리즈·슬롯 고정) 또는 경기 기록, 위반 목록, 미배정 풀 |
| 슬라이드 패널 | 공통 입력·검토·품질·분석·운영 패널. ⇔로 넓게, Esc로 닫기 |

- 공휴일·경기 없는 날·휴식 예외를 바꾸면 "슬롯 다시 생성" 배너가 뜬다. 같은 날짜·연전의 배정은 유지된다.
- 경기 없는 기간 안의 하루를 해제하면 기간이 둘로 나뉘고, 인접한 날을 지정하면 기존 기간에 붙는다.
- 키보드: 시리즈에서 Enter → 대상 날짜/시리즈에서 Enter(이동·교환), ⇅ 손잡이에서 Enter 두 번(슬롯 교환), Ctrl+Z / Ctrl+Shift+Z.

## 실행

```bash
open index.html                         # file://로 바로 실행 (Kakao 외 모든 기능)
python3 -m http.server 8000       # Kakao 사용 시. 개발자 콘솔에 http://localhost:8000 등록
```

작업 상태는 `localStorage`의 `kbo-opus:alt-2:v1`에 자동 저장된다. 코어 테스트는 `node core/test/run-tests.js`.
