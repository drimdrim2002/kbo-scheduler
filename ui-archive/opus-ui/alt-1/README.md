# alt-1 편성 브리프 (Season Brief)

> 브랜치 `opus-ui/alt-1` · 요구사항 `KBO_OPUS_UI_REQUIREMENTS.md` §10

## 콘셉트

회의 자료를 만드는 실무자를 위한 **하나의 긴 문서형 페이지**다. 입력 → 검토 → 결과 → 분석 → 운영이 번호 붙은 문서 섹션으로 이어진다. 섹션을 확정하면 한 줄 요약 카드로 접히고, 목차에 진행 체크(✔ 확정 · ⚠ 확인 필요 · ⛔ 차단 · ○ 작성 중)가 쌓인다. 인쇄하면 그대로 회의 보고서가 된다.

시각 언어는 종이 보고서다. 명조 제목, 상아색 지면, 먹색 글자, 짙은 남색 강조, 넉넉한 여백, 이중선 머리띠를 쓴다.

| 01 구단·구장 | 구단 표(색·이름·구장·좌표·공유 구장 배지), 구장 검색 후보, 내장 SVG/Kakao 지도(마커 드래그) |
| 02 이동거리 행렬 | N×N 히트맵 편집, 대칭 편집, 도로계수, 누락 거리 추정(≈) |
| 03 시즌 일정 골격 | 개막·1차 종료·시즌 종료, 휴식 요일·예외일, 경기 없는 기간, 공휴일(법정 공휴일 불러오기) |

| 05 시리즈 | 목표·1차 경기 수, 홈/원정 분배, 연전 용량 표, 구단쌍 × 경기 수 행렬, JSON·프리셋 불러오기 |
| 06 특별 이벤트 | 개막전·어린이날·사용자 정의, 대진 지정(핀)·구장 지정(홈 의무), 모순 경고 |
| 07 입력 검토와 엔진 실행 | 요약, 사전 점검(통과·경고·차단 + 입력 화면 링크), 엔진 옵션·실행·일시정지·중지, 점수 추이 |
| 08 편성 결과 | 점수 배지, 실행 취소·핀 도구·스냅샷, 월간 캘린더(드래그 이동·교환, Δ 미리보기, 구단 필터), 위반 목록(규칙별, 클릭 시 이동), 미배정 풀, 슬롯 목록 |
| 09 품질 확인 | 구단 지표 비교표(채점/참고 구분, 정렬, 평균·편차·허용오차), Soft 분해, 스냅샷 저장·비교 |
| 10 분석 | 차트 12종, 지도 위 시즌 경로 재생 |
| 11 시즌 운영 | 경기 기록(일괄 처리, 결과 미입력), 진행 현황 게이지, 재편성(대상·옵션·실행·묶음 편집·RH 위반) |
| 12 구단별 일정표 | 구단 선택, 인쇄, 구단 CSV |
| 13 설정과 데이터 | H0-e 모드, 의무 구단, Kakao 키, 엔진(Mock/REST), 기준일, 내보내기·가져오기 |

- 섹션은 화면 가까이 오면 그린다(초기 로딩을 가볍게). 사전 점검의 "입력 화면 →" 링크와 위반 클릭은 해당 섹션으로 스크롤하고, 접혀 있으면 연다.
- 확정 상태는 프로젝트 `meta.brief.confirmed`에 저장되어 내보내기에 포함된다.

## 실행

```bash
# 1) 파일로 바로 열기 (Kakao 외 모든 기능)
open index.html

# 2) Kakao 지도를 쓸 때: 로컬 서버로 열고 Kakao 개발자 콘솔에 http://localhost:8000 을 등록
python3 -m http.server 8000   # → http://localhost:8000
```

- 라이브러리·CDN·빌드 도구가 없다. 프리셋은 `core/preset-2025.js`에 내장되어 있다.
- 작업 상태는 `localStorage`의 `kbo-opus:alt-1:v1`에 자동 저장된다(대안마다 키가 다르다).
- 코어 테스트: `node core/test/run-tests.js`
