계획 흐름 시안 — 값 입력·검증 → 엔진 옵션·실행 → 결과 분석

2026-10-31 사용자가 다시 잡은 흐름. 지난 시안(demo-flow-concepts)의 「2027 모두 ✓ → 바로 실행」(4~7번 화면)을 이 시안이 대신합니다. 정적 시안이라 실제 스튜디오는 아직 바꾸지 않았습니다. 표준 10장 + 한 영역씩만 다른 대안 3장.

순서
처음 화면→2025 결과 보기(강조 · 보기 전용) 또는 2027 값 입력·검증(1 구단 정보 → 2 시즌 기간 → 3 공휴일·홈 구장 → 4 확인)→엔진 옵션·실행→결과 분석→버전 저장 · 비교 · 옵션 바꿔 다시
  • 정한 것: 목적식 우선순위는 순서만 정함(위가 조금이라도 나으면 그쪽) · 허용 차이는 가장 많은 구단과 가장 적은 구단의 차이 · 넘으면 줄이려 노력(반드시는 아님) · 주말과 공휴일은 한 점수로 합침(주말 하루 1점 · 공휴일 2점 · 어린이날 3점, 지금 엔진 그대로).
  • 숫자는 모두 실제로 돌린 값입니다. 2025 이 엔진 = 저장된 결과(10/20 실행), 2027 기본안 = 2027 원칙 입력으로 엔진 28.7초, 2027 개막 대진 바꾼 안 = 같은 방식 19.4초. 모두 브라우저 채점기로 다시 셌습니다.
  • 엔진을 고쳐야 하는 것 두 가지: (1) 목적식 순서가 지금은 코드에 고정(이동 횟수 → 이동 거리 → 주말·공휴일 → 전체 거리) → 화면에서 정한 순서를 받도록. (2) 허용 차이가 지금은 「리그 평균 ±값」 방식 → 「가장 많은·적은 구단 차이」로. 그래서 순서를 바꾼 결과의 숫자는 아직 없습니다(대안 A의 추천 순서 카드에 숫자를 넣지 않은 이유).
  • 허용 차이 기본값 4회 · 600km · 3점은 지금 엔진 기본값(평균 ±2회 · ±300km · ±1.5점)을 차이로 옮긴 제안값입니다. 결과에 맞춰 고른 값이 아닙니다 — 2027 기본안의 이동 거리 차이 594.4km는 600km에 거의 붙어 있습니다.
  • 주의 — 엔진 결과가 실행마다 흔들립니다. 2025를 오늘 엔진으로 다시 돌리면 69,821km(KBO보다 4% 짧음), 출발점 하나하나는 63,312~73,960km였습니다. 2025 화면의 −13%는 저장된 가장 좋은 결과입니다. 표준 10과 대안 C에 「전체 이동 거리가 수천 km씩 달라질 수 있으니 다시 실행해 확인」 안내를 넣었습니다.
  • 따라 하기 모양은 지금 스튜디오의 「따라 하기 카드」를 그대로 썼습니다. 모양(카드 · 체크리스트 · 말풍선)은 아직 고르지 않은 초기화·튜토리얼 3안 브랜치에서 고르시면 됩니다.
고른 조합 (2026-10-31 사용자 결정) — 엔진 옵션은 대안 A, 결과 분석은 대안 B, 결과 비교는 네 번째 단계 「실행 결과 비교」로 따로 둡니다(대안 C는 쓰지 않음). 단계 띠는 4칸: 값 입력·검증 → 엔진 옵션·실행 → 현재 결과 분석 → 실행 결과 비교.
처음 화면→2025 결과 또는 1 값 입력·검증(1 · 2 · 3 · 4)→2 엔진 옵션(A)→실행 중→3 현재 결과 분석(B)→4 실행 결과 비교
  • 「실행 결과 비교」는 순서대로 가는 단계가 아니라 저장한 버전이 있으면 언제든 누를 수 있는 탭입니다. 버전 저장은 3 현재 결과 분석에서 합니다.

정해 주실 것

  • 영역마다 하나씩: 엔진 옵션(표준 7 끌어서 순서 / 대안 A 추천 순서 카드 + 그림) · 결과 분석(표준 9 탭 / 대안 B 한 장 대시보드) · 버전(표준 10 별도 화면 / 대안 C 옆 칸에서 겹쳐 비교). → 정함: A · B · 4단계 「실행 결과 비교」.
  • 추정값이 5개(개막일 · 1차 편성 끝나는 날 · 올스타 휴식기 · 개막전 홈 · 어린이날 홈)로 맞나요? 더 있거나 확정된 것이 있으면 알려 주세요.
  • 허용 차이 기본값 4회 · 600km · 3점으로 시작해도 될까요?
  • 실행 중 시간: 지금은 「0:20 지남」을 작게 보여 줍니다. 아예 숨길까요?
  • 「이동일수 균형」이라고 하셨는데, 화면은 엔진 목적식 그대로 이동 횟수(다른 도시로 옮겨 간 횟수)로 썼습니다. 같은 뜻인가요, 아니면 이동한 날 수(이동일)를 따로 세길 원하시나요?
  • 2025 강조 숫자: 저장된 가장 좋은 결과(−13%)를 쓸까요, 아니면 시연 전에 엔진을 길게 다시 돌려 새로 저장할까요?
