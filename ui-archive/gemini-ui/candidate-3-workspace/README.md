# KBO Planner Workspace (후보 3: Split-Pane Interactive Calendar & Spreadsheet Workspace)

KBO 정규시즌 일정 편성 실무자가 **엑셀 스프레드시트(10×10 구장 이동거리 시트·구단 비교표)**와 **시즌 캘린더(3~8월 전체 달력 그리드·이벤트 빌더)**를 한 화면에서 동시에 다루는 업무 흐름에 최적화된 **100% Pure Vanilla HTML5 / CSS3 / JavaScript** 모던 생산성 SaaS 워크스페이스 템플릿입니다.

---

## 1. 디자인 & 아키텍처 컨셉

- **테마**: Linear · Notion Calendar · Airtable 감성의 크리습 라이트(`#F8FAFC` / `#FFFFFF`) + 인디고(`#4F46E5`) + 다크 슬레이트 독(`#0F172A`) 3단 분할 워크스페이스.
- **3-Column Split-Pane 구조**:
  1. **좌측 워크스페이스 독 (`aside.workspace-dock`)**: 4대 핵심 공정 탭(`⌥1 ~ ⌥4`), 10개 구단 빠른 필터 칩, 실시간 OptaPlanner Hard/Soft Score 요약 카드 및 즉시 실행 버튼.
  2. **중앙 메인 캔버스 (`main.workspace-canvas`)**: 각 단계별 분할 작업 공간(스프레드시트 + 지도, 3~8월 인터랙티브 달력 + 이벤트 빌더, Pre-flight 점검 시트 + 솔버 콘솔, Hard 검증 + Soft 비교 시트 + 5종 차트).
  3. **우측 컨텍스트 인스펙터 (`aside.inspector-drawer`)**: 선택한 구단의 타 구장 이동거리 및 시즌 45시리즈 전체 경로 로그 조회, 또는 선택한 날짜의 대진·홈/원정 실시간 스왑 및 이벤트 편집.

---

## 2. 필수 요구사항 구현 내역

### Step 1. 구단 정보 & 위경도 자동 완성 & 지도 기반 구장 별 거리 계산
- **구단·구장 스프레드시트 에디터**: 10개 구단(`SSG, 두산, LG, KT, 키움, 한화, 삼성, KIA, NC, 롯데`)의 구단명, 홈구장명, 위도, 경도를 엑셀 셀처럼 직접 편집 가능.
- **구장 위치 입력 시 위경도 자동 입력 (`KBOEngine.geocodeLocation`)**:
  - 구장명/도시/주소를 입력 후 `Enter` 또는 `[좌표자동]` 클릭, 혹은 상단 **13개 구장 프리셋 칩**(문학·잠실·수원·고척·대전·대구·광주·창원·사직 + 제2구장 포항·울산·청주·군산) 클릭 시 위경도가 즉시 자동 입력됩니다.
- **멀티 엔진 지도 시각화**:
  - **Leaflet 오픈스트리트맵** (즉시 동작, 선택 구단과 타 구장 간 연결선 및 거리 툴팁 표시)
  - **내장 SVG 대한민국 구장 벡터 지도** (오프라인 `file://` 환경에서도 100% 동작 보장)
  - **Kakao Map / Naver Map JS SDK 로더** (API Key 입력 시 동적 스크립트 로드 지원)
- **위경도 기반 10×10 전 구장 이동거리 자동 계산**:
  - `[📍 위경도 기반 전 구장 이동거리 계산 (Map API)]` 버튼 클릭 시 위경도 좌표(및 선택적 OSRM 실시간 도로 경로 API)를 기반으로 10×10 구단 간 이동거리 행렬이 일괄 재계산되며, 대칭 행렬(`A↔B`) 자동 동기화 및 셀 단위 직접 편집을 지원합니다.

### Step 2. 일정 정보 (시즌 기간, 월요일 정기휴일, 특정 이벤트, 올스타 브레이크, 시즌 달력 UI)
- **정규시즌 운영 기간**: `2025-03-22` ~ `2025-08-31` (총 45개 시리즈 슬롯, 225개 시리즈 매치, 총 675경기).
- **정기 휴식일 설정 (기본값: 매주 월요일)**:
  - 요일 토글 칩에서 월요일이 기본 체크되어 달력의 월요일 열 전체에 `휴식일 (REST)` 배지와 해칭 패턴이 표시됩니다 (`5/5 어린이날`은 예외로 특별 3연전 허용).
- **특정 이벤트 빌더 (`[구단 및 구장 모두 지정]` vs `[구장만 지정]`)**:
  - **구단 및 구장 모두 지정**: 예) `2025-03-22 개막 2연전` (`롯데 vs LG @잠실종합운동장` 등 원정구단·홈구단·개최구장 모두 확정).
  - **구장(홈구단)만 지정**: 예) `2025-05-05 어린이날 3연전` (`@잠실(두산), @고척(키움), @대전(한화), @창원(NC), @사직(롯데)` 5개 홈구장만 고정하고 상대 원정 구단은 엔진이 자동 배정).
- **올스타 브레이크 (`2025-07-11 ~ 2025-07-16`)**:
  - 달력 상에 보라색 브레이크 블록으로 시각화되며 해당 기간 중 경기 편성 시 Hard 제약 위반으로 즉시 탐지됩니다.
- **3가지 달력 미리보기 뷰**: `📅 3~8월 월별 달력 그리드` / `📋 45시리즈 시트` / `🔢 10×10 구단 대진표`.

### Step 3. 최종 입력 확인 (Pre-flight Check) 및 엔진 실행 화면
- **Pre-flight 요약 시트**: 구단·구장·거리행렬, 시즌 달력·휴식일·올스타 브레이크, 고정 이벤트 현황을 한눈에 점검.
- **제약 파라미터 실시간 슬라이더**: 이동거리 허용오차(`±300km`), 총 이동횟수 허용오차(`±2.0회`), 공휴일 점수 허용오차(`±1.5점`), 최대 연속 홈/원정 시리즈(`3연속`) 조정 시 즉시 스코어 재산출.
- **OptaPlanner 엔진 실행 시뮬레이터**: 4단계 파이프라인 진행 표시, 실시간 Soft Score 수렴 캔버스 차트, 콘솔 로그 스트림 제공.

### Step 4. 엔진 실행 결과 확인 화면 (Hard 검증 + 구단별 Soft 비교 시트 + 5대 차트)
- **Hard 제약조건 6대 항목 검증 보드**:
  - 상단 `[최적화 결과(Hard 0)]` / `[초기 배정안]` / `[위반 테스트안(Hard 위반)]` 전환 버튼으로 6개 Hard 조건(구단 중복 금지, 잠실 공동구장 중복 금지, 연전 수 일치, 개막/어린이날/휴식일/올스타 준수, 최대 3연속 홈/원정, 연속 맞대결 금지)의 통과/위반 내역을 즉시 검증.
- **구단별 Soft Constraints 비교 스프레드시트**:
  - 구단별 `총 이동거리(km)`, `평균 대비 편차`, `±300km 준수 여부`, `총 이동 일수`, `주중 이동 일수`, `주말 이동 일수`, `주말 홈경기`, `공휴일 홈경기`, `휴일 종합점수`, `최대 연속 홈/원정` 비교 및 정렬.
- **순수 HTML5 Canvas / SVG 5대 분석 차트**:
  1. **차트 1**: 구단별 총 이동거리 & 평균±300km 녹색 허용오차 밴드 차트 (초기 배정안 오버레이 비교 지원)
  2. **차트 2**: 구단별 총 이동 일수 vs 주중(화~목→금) 이동 일수 비교 가로 막대 차트
  3. **차트 3**: 구단별 주말 홈경기 수 & 공휴일 홈경기 / 휴일 점수 복합 차트
  4. **차트 4**: 구단별 5대 지표 종합 레이더 차트 (임의의 두 구단 선택 맞비교)
  5. **차트 5**: 구단별 월별(3~8월) 이동거리 히트맵 & 시즌 전체 45시리즈 홈(`H`)/원정(`A`) 간트(Gantt) 스트립
