`optaplanner-practice` 프로젝트의 **KBO 정규시즌 일정 최적화 엔진(`BaseballEasyScoreCalculator.java` & `input_2025.json`)** 을 위한 **순수 Vanilla HTML5 / CSS3 / JavaScript 기반 4단계 가이드 위저드(Step-by-Step Guided Wizard) UI 템플릿**입니다.

## ✨ 디자인 컨셉 & 핵심 특징

  - `BaseballEasyScoreCalculator.java`의 Hard/Soft 제약 평가 로직을 1:1 포팅한 `window.KBOEngine.evaluatePlan()` 탑재

## 🧭 4단계 위저드 구성 (Step 1 ~ Step 4)

### 1️⃣ [Step 1] 구단·구장 위치(위경도 자동 변환) & 지도 기반 10×10 이동거리 산출
- **구장 위치 입력 시 위도·경도 자동 변환**: 구장명(예: `잠실`, `사직`, `포항야구장`, `울산문수야구장`, `청주야구장`)이나 도로명주소를 입력하고 `[📍 변환]`을 클릭하면 `window.KBOEngine.geocodeLocation()`이 호출되어 위경도가 자동 입력되고 지도가 즉시 갱신됩니다.
- **4-Tab 통합 지도 뷰**:
  - `🌐 한국 지도 (Leaflet / OSM)`: 즉시 동작하는 인터랙티브 지도 + 구단 마커 + 기준 구단별 이동 경로선 및 거리(km) 표시
  - `📐 고해상도 벡터 네트워크 맵 (Canvas)`: 오프라인에서도 100% 동작하는 한반도 윤곽선 및 10개 구장 네트워크 맵
  - `🟡 Kakao Map` / `🟢 Naver Map`: API Key 입력 시 실제 SDK를 동적으로 로드하는 연동 로더 내장
- **10×10 구장 간 이동거리 일괄 계산 & 히트맵**:
  - `[🚗 구장 간 이동거리 일괄 계산 (Map Route API)]` 클릭 시 모든 구장의 위경도를 기반으로 100개 구간 도로 이동거리를 계산하며, 히트맵 셀에서 직접 수동 미세조정(양방향 대칭 동기화 지원)도 가능합니다.

### 2️⃣ [Step 2] 정규시즌 기간, 정기 휴식일, 올스타 브레이크 & 특정 이벤트 설정
- **정규시즌 시작일 ~ 종료일**: `2025-03-22 ~ 2025-08-31` (45개 슬롯 · 225 시리즈) 설정
- **요일별 정기 휴식일 토글**: 기본적으로 **매주 월요일(`월`)** 이 정기 휴식일로 활성화되어 있으며, 요일 버튼을 클릭해 변경 가능
- **올스타 브레이크 및 경기 미개최 일자(Blackout Dates)**: `2025-07-11 ~ 2025-07-16` 올스타 브레이크 및 커스텀 미개최 일자 추가/삭제
- **특정 이벤트 경기 고정 (2가지 모드 완벽 지원)**:
  - **모드 A (구단 매치업 + 구장 모두 지정)**: 개막전(`2025-03-22`) 5경기의 `원정팀 vs 홈팀 @구장` 직접 지정
  - **모드 B (개최 구장/홈구단만 단독 지정)**: 어린이날(`2025-05-05`) 개최 5개 구장(`잠실-두산`, `고척-키움`, `대전-한화`, `창원-NC`, `사직-롯데`)만 체크하고 상대 원정 구단은 엔진이 자동 배정하도록 설정
- **인터랙티브 3월~8월 시즌 달력 & 슬롯 인스펙터**: 설정한 시리즈, 월요일 휴식일, 올스타 브레이크, 개막전/어린이날 이벤트가 달력에 한눈에 표시되며, 날짜 클릭 시 우측 인스펙터에서 5경기 대진을 확인하고 홈/원정 공수 교대 실험도 가능합니다.

### 3️⃣ [Step 3] 입력 결과 최종 확인 (Pre-flight Check) & OptaPlanner 엔진 실행
- **사전 검증(Pre-flight) 요약 카드**: 구단/구장 좌표, 시즌 캘린더/휴식일, 개막전/어린이날 고정 조건, 탐색 공간 검증
- **Soft Constraint 허용 편차(Tolerance) 실시간 슬라이더**:
  - 총 이동거리 편차(`±300.0 km`), 총 이동 횟수 편차(`±2.0 회`), 주중 이동 편차(`±1.5 회`), 휴일 점수 편차(`±1.5 점`), 최대 연속 홈/원정 시리즈(`3연속`)
- **OptaPlanner 최적화 실행 콘솔**:
  - `[🚀 일정 최적화 엔진 실행 (Run OptaPlanner)]` 클릭 시 Construction Heuristic → Local Search 단계별 진행률, 실시간 **Canvas 수렴 곡선(총 이동거리 & 구단 간 최대 편차)**, 솔버 콘솔 로그가 역동적으로 출력됩니다.

### 4️⃣ [Step 4] 엔진 실행 결과 검증 (Hard 제약 스코어카드 + Soft 비교표 + 4종 차트 + 대진표)
- **6대 Hard 제약 조건 스코어카드**:
  - ① 1일 10구단 5경기 편성, ② 구장 중복 배정 금지(잠실 두산·LG 분리), ③ 연전 수 일치, ④ 개막전·어린이날·휴식일·올스타브레이크 준수, ⑤ 최대 3연속 홈/원정 제한, ⑥ 동일 대진 연속 시리즈 금지
  - 상단 `[🧪 Hard 위반 시뮬레이션 샘플 보기]` 클릭 시 잠실 중복·어린이날 위반·연속 대진 위반이 빨간색 카드로 즉시 검출되는 모습을 체험할 수 있습니다.
- **4종 고해상도 순수 Canvas 인터랙티브 차트**:
  1. **구단별 총 이동거리 & 허용 편차(±300km) 밴드 차트** (리그 평균선 + 녹색 허용 오차 밴드 + 초기안 대비 비교 막대)
  2. **구단별 이동 일수(주중 이동 vs 주말 이동) & 주말·공휴일 홈경기 수 비교 차트**
  3. **구단별 5대 지표 밸런스 레이더(오각형) 차트** (원하는 구단 선택 시 겹쳐서 비교)
  4. **시즌 누적 이동거리 피로도 곡선 & 45시리즈 방문 구장 이동 경로 시퀀스 트랙**
- **10개 구단 Soft 제약 종합 비교 성적표 (정렬 지원) & 225시리즈 대진표 탐색기 (CSV/JSON 다운로드)**
